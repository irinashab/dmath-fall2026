Definition of Relations

Definition: Let \(X\) and \(Y\) be sets. A binary relation \(R\) from \(X\) to \(Y\) is a subset of \(X \times Y\), that is, a set of ordered pairs \((x, y)\) where \(x \in X\) and \(y \in Y\).

  • \(X\) is the domain of \(R\), \(Y\) is the codomain.
  • If \(X = Y\), we say \(R\) is a "relation on \(X\)".
  • We can think of it as a formula \(R(x, y)\).
  • We write \(x \, R \, y\) for \((x, y) \in R\) or \(R(x, y)\).

Examples of Relations

Order Relations

Classical example: \(x, y \in \mathbb{Z}\), \(R\) is \(<\).

  • \(0 < 1\) means "0 is less than 1".
  • This adds structure to \(\mathbb{Z}\).
  • Sets have no structure: just elements.
  • Relations add structure: how elements relate to each other.

Rock, Paper, Scissors

Let \(X = \{\text{rock, paper, scissors}\}\). Let \(x \, R \, y\) mean "\(x\) beats \(y\) in a game of rock/paper/scissors".

\(R\) is completely described by:

  • rock beats scissors
  • scissors beats paper
  • paper beats rock

So \(R = \{(\text{rock, scissors}), (\text{scissors, paper}), (\text{paper, rock})\}\).

Properties of Relations

Let \(R\) be a relation on a set \(X\). Then:

  • Reflexive: \(\forall x \in X,\; x \, R \, x\).
  • Symmetric: \(\forall x, y \in X,\; x \, R \, y \rightarrow y \, R \, x\).
  • Transitive: \(\forall x, y, z \in X,\; x \, R \, y \land y \, R \, z \rightarrow x \, R \, z\).
  • Antisymmetric: \(\forall x, y \in X,\; x \, R \, y \land y \, R \, x \rightarrow x = y\).
  • Asymmetric: \(\forall x, y \in X,\; x \, R \, y \rightarrow \neg(y \, R \, x)\).

Antisymmetric vs. asymmetric

On \(\mathbb{Z}\), the relation \(\le\) is antisymmetric (if \(x \le y\) and \(y \le x\), then \(x = y\)) but not asymmetric (since \(x \le x\) is true, so \(x \le y \to \neg(y \le x)\) fails when \(x = y\)).

The relation \(<\) is both antisymmetric and asymmetric.

Equivalence Relations

Definition: A relation \(\sim\) on \(X\) is an equivalence relation if it is:

  1. Reflexive: \(\forall x \in X,\; x \sim x\).
  2. Symmetric: \(\forall x, y \in X,\; x \sim y \rightarrow y \sim x\).
  3. Transitive: \(\forall x, y, z \in X,\; x \sim y \land y \sim z \rightarrow x \sim z\).

Equivalence relations generalize notions of "sameness":

  • \(x = y\)
  • \(x \equiv y \pmod{n}\)
  • Cardinality: \(|A| = |B|\)
  • Congruent shapes, similar triangles, etc.

Example: Congruence modulo 3 is an equivalence relation on \(\mathbb{Z}\).

Function-Induced Equivalence Relations

Many of the examples we have seen are instances of a single general fact:

Theorem. Let \(f : X \to Y\) be any function. Define a relation \(\sim\) on \(X\) by \[ x \sim y \iff f(x) = f(y). \] Then \(\sim\) is an equivalence relation on \(X\).

Proof sketch. Reflexivity: \(f(x) = f(x)\). Symmetry: if \(f(x) = f(y)\), then \(f(y) = f(x)\). Transitivity: if \(f(x) = f(y)\) and \(f(y) = f(z)\), then \(f(x) = f(z)\). \(\square\)

Instances.

  • \(f(x) = x^2\) on \(\mathbb{Z}\) gives \(x \sim y \iff x^2 = y^2\).
  • \(f(x) = \sin x\) on \(\mathbb{R}\) gives \(x \sim y \iff \sin x = \sin y\).
  • \(f(x) = x \bmod n\) on \(\mathbb{Z}\) gives congruence modulo \(n\).
  • \(f(x) = \operatorname{sign}(x)\) on \(\mathbb{R}\) gives classes \(\{x < 0\}\), \(\{0\}\), \(\{x > 0\}\).
  • \(f(n) = \lfloor n/2 \rfloor\) on \(\mathbb{N}\) gives classes of size 2 (e.g. \(\{0,1\}, \{2,3\}, \ldots\)).

Equivalence Classes

Definition: Let \(\sim\) be an equivalence relation on \(X\).

  • The equivalence class of \(x\) is \([x]_{\sim} = \{y \in X : x \sim y\}\).
  • The quotient of \(X\) by \(\sim\) is \(X/{\sim} = \{[x]_{\sim} : x \in X\}\).
  • \(x\) is called a representative of its equivalence class \([x]_{\sim}\).

Modular Arithmetic Examples

  • \(X = \mathbb{Z}\), \(\sim\) is \(\equiv \pmod{2}\):
    • Equivalence classes: evens and odds.
    • \(X/{\sim} = \{[0]_{\sim}, [1]_{\sim}\}\).
  • \(X = \mathbb{Z}\), \(\sim\) is \(\equiv \pmod{10}\):
    • Equivalence classes: numbers with the same last digit.
    • \(X/{\sim} = \{[0]_{\sim}, [1]_{\sim}, \ldots, [9]_{\sim}\}\).

Squares Example

Let \(X = \mathbb{Z}\), and \(x \sim y\) if \(x^2 = y^2\).

Claim: \(\sim\) is an equivalence relation.

Proof: This is the function-induced relation with \(f(x) = x^2\), so the theorem above applies.

  • \([0]_{\sim} = \{0\}\).
  • \([1]_{\sim} = \{1, -1\}\).
  • \([2]_{\sim} = \{2, -2\}\).
  • There is one equivalence class for each non-negative integer.
  • Good set of representatives: \(\mathbb{N} \cup \{0\}\).

Sine Example

Let \(X = \mathbb{R}\) and \(x \sim y\) if \(\sin(x) = \sin(y)\).

Claim: \(\sim\) is an equivalence relation.

Proof: This is the function-induced relation with \(f(x) = \sin x\).

  • \([0]_{\sim} = \{k\pi : k \in \mathbb{Z}\}\).
  • \([\pi/2]_{\sim} = \{\pi/2 + 2\pi k : k \in \mathbb{Z}\}\).
  • There is one equivalence class for each value in the range \([-1, 1]\) of sine.
  • Good set of representatives: \([-\pi/2, \pi/2]\) (each \(y\)-value appears exactly once).

Exercise: \(f(n) = \lfloor n/2 \rfloor\)

Let \(f : \mathbb{N} \to \mathbb{N}\) be \(f(n) = \lfloor n/2 \rfloor\) (integer division by 2). Define \(n \sim m\) iff \(f(n) = f(m)\). Compute:

  1. \([0]\)
  2. \([3]\)
  3. \([4]\)
  4. \([2k]\)
  5. \([2k+1]\)

  • \([3] = \{6, 7\}\)

Partitions

Definition. A partition of a set \(X\) is a collection of nonempty subsets \(\{U_i\}\) of \(X\) such that:

  • if \(i \neq j\), then \(U_i \cap U_j = \emptyset\) (the parts are pairwise disjoint), and
  • for every \(x \in X\), there is some \(i\) with \(x \in U_i\) (the parts cover \(X\)).

So every element of \(X\) lies in exactly one part.

Equivalence classes form a partition

Let \(\sim\) be an equivalence relation on \(X\). The equivalence classes \(\{[x]_{\sim} : x \in X\}\) form a partition of \(X\):

  • Cover: every \(x\) lies in \([x]_{\sim}\) (reflexivity).
  • Disjoint: if \([x] \cap [y] \neq \emptyset\), say \(z \in [x] \cap [y]\), then \(x \sim z\) and \(y \sim z\), so by symmetry and transitivity \(x \sim y\), hence \([x] = [y]\).

Recovering a relation from a partition

Conversely, given a partition of \(X\), define \(x \sim y\) iff \(x\) and \(y\) lie in the same part. This is an equivalence relation, and its equivalence classes are exactly the parts of the partition.
