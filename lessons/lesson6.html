1. Countability and bijections

A set is countably infinite if there is a bijection from \(\mathbb N\) to it. We use \(\mathbb N=\{0,1,2,\ldots\}\). A set is countable if it is finite or countably infinite; otherwise it is uncountable. We will use these meanings consistently.

The cardinality of \(\mathbb N\) is denoted \(\aleph_0\), pronounced “aleph naught.” Last time, \(f(n)=2n\) gave a bijection \(\mathbb N\to2\mathbb N\), so the even natural numbers also have cardinality \(\aleph_0\).

Listing a countably infinite set means arranging its elements as \(a_0,a_1,a_2,\ldots\), with every element appearing exactly once at a finite index. The associated bijection is \(n\mapsto a_n\).

Retrieve the function tools

Suppose \(f:A\to B\) and \(g:B\to C\) are bijections.

  1. Which function establishes \(|B|=|A|\)?
  2. Which function establishes \(|A|=|C|\)?
  3. Which function establishes \(|A|=|A|\)?
Show solution

The inverse \(f^{-1}:B\to A\) establishes symmetry. Every target of \(f\) has exactly one preimage, so the inverse is well-defined and bijective.

The composition \(g\circ f:A\to C\) establishes transitivity. Equal outputs imply equal intermediate values by injectivity of \(g\), then equal inputs by injectivity of \(f\). Given \(c\in C\), choose \(b\in B\) with \(g(b)=c\), then \(a\in A\) with \(f(a)=b\); thus \(g(f(a))=c\).

The identity function establishes reflexivity. These properties show that our definition of equal cardinality behaves as equality should.

Our definition uses a bijection in one direction. The inverse verifies that reversing the direction gives an equivalent condition; composition lets us connect two comparisons.

2. Listing all integers

The integers include all natural numbers and all negative integers. We can list them by alternating outward from zero:

\[0,-1,1,-2,2,-3,3,\ldots.\]

The corresponding function \(f:\mathbb N\to\mathbb Z\) is

\[f(n)=\begin{cases}n/2,&n\text{ even},\\-(n+1)/2,&n\text{ odd}.\end{cases}\]

Even natural-number inputs give nonnegative integers; odd natural-number inputs give negative integers. Define the odd natural numbers as \(\mathbb O=\{2k+1:k\in\mathbb N\}\). Then \(f(2\mathbb N)=\mathbb N\) and \(f(\mathbb O)=\{-1,-2,-3,\ldots\}\).

Find the position

Given an integer \(z\), find its natural-number index in this list. Consider separately \(z\ge0\) and \(z<0\). Explain why the index is unique.

Show solution

If \(z\ge0\), choose \(n=2z\in\mathbb N\). It is even and \(f(n)=z\). Any input giving a nonnegative output must be even, and \(n/2=z\) forces \(n=2z\).

If \(z<0\), choose \(n=-2z-1\). This is a positive odd integer and \(f(n)=-((-2z-1)+1)/2=z\). Any input giving a negative output must be odd, and \(-(n+1)/2=z\) forces this same value of \(n\).

Every integer therefore occurs at exactly one index. This proves that \(f\) is bijective and \(|\mathbb Z|=\aleph_0\).

A quick composition check

Let \(d:2\mathbb N\to\mathbb N\) be \(d(y)=y/2\). The composite \(F=f\circ d\) is a bijection from the even natural numbers to the integers. Compute \(F(0),F(2),F(4)\).

Show solution\[F(0)=f(0)=0,\quad F(2)=f(1)=-1,\quad F(4)=f(2)=1.\]

We know the composite is bijective because both component functions are bijective.

Why this attempted list fails

\[0,1,2,3,\ldots,-1,-2,-3,\ldots\]

At which natural-number index would \(-5\) appear?

Show solution

There is no such index. Listing all the nonnegative integers first never reaches a point at which the negative integers begin. A valid enumeration must reach every element after finitely many steps.

3. Listing the rational numbers

Start with the positive rationals \(\mathbb Q_{>0}\). Put \(m/n\) in row \(m\), column \(n\), with row and column indices starting at 1.

Reading an entire row before starting the next would never reach the second row. Instead, visit successive finite diagonals:

\[m+n=2,3,4,5,\ldots.\]

Move back and forth along those diagonals in a zigzag, retaining only fractions in lowest terms.

The resulting list begins

\[1,2,\frac12,\frac13,3,4,\frac32,\frac23,\frac14,\ldots.\]

Three things to justify

  1. Coverage: why does every positive rational number occur?
  2. No repetitions: why retain only fractions in lowest terms?
  3. Finite position: why is every retained fraction reached after finitely many steps?
Show solution

Coverage. Every positive rational has a representation \(p/q\) with positive integers \(p,q\) having no common divisor greater than 1. This entry appears in the array and is retained.

No repetitions. A positive rational has a unique lowest-terms representation with positive numerator and denominator. Keeping these representations prevents entries such as \(1/1\), \(2/2\), and \(3/3\) from repeating the same number.

Finite position. The entry \(p/q\) lies on diagonal \(p+q\). Each earlier diagonal is finite, and there are only finitely many earlier diagonals. Thus the entry is reached after finitely many steps. Omitting reducible entries cannot delay it.

There are infinitely many retained entries, including every positive integer. Numbering them from zero gives a bijection \(\mathbb N\to\mathbb Q_{>0}\).

Include zero and negative rationals

Suppose \(r_0,r_1,r_2,\ldots\) lists every positive rational exactly once. Explain why

\[0,r_0,-r_0,r_1,-r_1,r_2,-r_2,\ldots\]

lists all of \(\mathbb Q\) exactly once.

Show solution

Zero occurs at index 0. Each positive rational \(r_k\) occurs at index \(2k+1\), and its negative occurs at index \(2k+2\). These positions are finite and distinct. The positive list has no repetitions, and positive, negative, and zero entries cannot coincide. Therefore \(\mathbb Q\) is countably infinite.

Optional extension: how could diagonal traversal and the enumeration of \(\mathbb Z\) be combined to list all ordered pairs of integers?

Show solution

First list pairs \((i,j)\in\mathbb N^2\) by the finite diagonals \(i+j=0,1,2,\ldots\). Replace each pair with \((f(i),f(j))\), where \(f:\mathbb N\to\mathbb Z\) is our bijection. Each integer pair has unique preimage coordinates, so it occurs exactly once at a finite position.

4. A set that cannot be listed

Not finding a clever enumeration is not a proof of uncountability. We need an argument that defeats every proposed list.

An infinite binary sequence is a function \(s:\mathbb N\to\{0,1\}\). Its entries are \(s(0),s(1),s(2),\ldots\). Let \(\mathcal B\) be the set of all such sequences. Unlike the finite strings from Lesson 5, these sequences have no last position.

Take any proposed list \(s_0,s_1,s_2,\ldots\) of infinite binary sequences. The list need not have distinct rows: we will show that it fails to reach every sequence regardless.

Here is an illustrative beginning. The bold entries lie on the diagonal: row \(n\), position \(n\).

\[\begin{array}{c|ccccc} &0&1&2&3&\cdots\\\hline s_0&\mathbf{0}&1&0&1&\cdots\\ s_1&1&\mathbf{1}&0&0&\cdots\\ s_2&0&0&\mathbf{1}&1&\cdots\\ s_3&1&0&1&\mathbf{0}&\cdots\\ \vdots&\vdots&\vdots&\vdots&\vdots&\ddots \end{array}\]

Construct a missing sequence

Define a new sequence by flipping the diagonal bits:

\[t(n)=1-s_n(n).\]

In the illustrative table, \(t\) begins \(1,0,0,1,\ldots\).

  1. Why is \(t\) a valid infinite binary sequence?
  2. Why is \(t\ne s_0\)? Why is \(t\ne s_1\)?
  3. For an arbitrary index \(k\), which position proves \(t\ne s_k\)?
Show solution

Each value \(s_n(n)\) is 0 or 1, so \(t(n)=1-s_n(n)\) is also 0 or 1. Thus \(t\in\mathcal B\).

At position 0, \(t(0)\ne s_0(0)\); at position 1, \(t(1)\ne s_1(1)\). More generally, for every \(k\in\mathbb N\),

\[t(k)=1-s_k(k)\ne s_k(k).\]

Two functions are different if they differ at even one input. Therefore \(t\ne s_k\) for every \(k\). The proposed list misses \(t\).

This argument works for any list, so no function \(\mathbb N\to\mathcal B\) is surjective. Every nonempty finite set can be covered by a repeating list, and every countably infinite set can be listed bijectively. Since \(\mathcal B\) is nonempty and cannot be covered by any list, it is uncountable.

What the quantifiers say

For every proposed list, we construct a sequence missing from that list. The constructed sequence depends on the list. We do not claim that one fixed sequence is absent from every possible list.

Nor must \(t\) differ from every row at every position. One carefully chosen difference per row is enough. This is Cantor’s diagonal argument.

5. The real numbers are uncountable

Adapt the same idea to the interval \((0,1)\). Suppose someone proposes a list \(x_0,x_1,x_2,\ldots\) of all real numbers in this interval.

Decimal representations need care: \(0.4999\ldots=0.5000\ldots\). For each listed number, choose the representation that does not end in repeating 9s; write terminating decimals with trailing zeros.

Write

\[x_n=0.d_{n,1}d_{n,2}d_{n,3}\ldots.\]

Rows are indexed from 0, while decimal places are indexed from 1. To change the diagonal, use digit \(n+1\) of row \(n\).

A precise construction

Define \(r=0.c_1c_2c_3\ldots\) by

\[c_{n+1}=\begin{cases}2,&d_{n,n+1}=1,\\1,&d_{n,n+1}\ne1.\end{cases}\]

We are defining digits of the new number \(r\), not changing the proposed list. Here is an illustrative list:

\[\begin{array}{c|cccccc} x_0=0.&\mathbf{1}&3&1&5&6&\cdots\\ x_1=0.&7&\mathbf{1}&8&2&8&\cdots\\ x_2=0.&1&4&\mathbf{1}&5&9&\cdots\\ x_3=0.&7&4&1&\mathbf{2}&1&\cdots\\ x_4=0.&6&1&8&1&\mathbf{2}&\cdots \end{array}\]

The diagonal begins \(1,1,1,2,2\), so \(r\) begins \(0.22211\ldots\).

Finish the argument

  1. Why does the construction give a number in \((0,1)\)?
  2. Why is \(r\ne x_k\) for each index \(k\)?
  3. Why does the decimal ambiguity not spoil this argument?
Show solution

Every digit of \(r\) is 1 or 2, so \(0<r<1\). For each \(k\), digit \(k+1\) of \(r\) differs from digit \(k+1\) of \(x_k\).

Neither decimal expansion ends in repeating 9s, and \(r\) also does not terminate. The ambiguity between a terminating expansion and one ending in 9s therefore cannot identify these different digit strings as the same number. Hence \(r\ne x_k\).

The proposed list misses \(r\). Because the list was arbitrary, no list covers \((0,1)\), so this interval is uncountable.

From the interval to all real numbers

If \(\mathbb R\) could be listed, deleting entries outside \((0,1)\) would list all numbers in that interval. Every retained number would still be reached after finitely many steps. This contradicts what we just proved. Thus \(\mathbb R\) is uncountable.

Showing that one particular function misses a real number would not establish this result. The strength of the proof is that the construction applies to every proposed list.

6. Afterthought proofs

A list of subsets

Suppose \(A_0,A_1,A_2,\ldots\) is any proposed list of all subsets of \(\mathbb N\). Define

\[D=\{n\in\mathbb N:n\notin A_n\}.\]
  1. Why is \(D\) an element of \(\mathcal P(\mathbb N)\)?
  2. Fix an arbitrary \(k\). Explain why \(D\ne A_k\), considering whether \(k\in A_k\).
  3. What does this prove about \(\mathcal P(\mathbb N)\)?
Show hint

Compare membership of the single element \(k\) in \(D\) and \(A_k\). Recall that two sets are different if some element belongs to one and not the other.

Show solution

By definition, \(D\subseteq\mathbb N\), so \(D\in\mathcal P(\mathbb N)\). Let \(k\in\mathbb N\) be arbitrary.

  • If \(k\in A_k\), then \(k\notin D\).
  • If \(k\notin A_k\), then \(k\in D\).

In either case, the sets disagree on membership of \(k\), so \(D\ne A_k\). Thus the proposed list omits \(D\). Every proposed list fails, so \(\mathcal P(\mathbb N)\) is uncountable.

This is binary diagonalization in set notation: membership corresponds to 1 and nonmembership to 0.

Before you leave

  1. Explain why \(0,1,2,\ldots,-1,-2,\ldots\) is not an enumeration of \(\mathbb Z\).
  2. A student says, “The new sequence differs from the first four rows, so it is not on the list.” What is missing from that argument?
Review after writing your answers

The first expression never reaches a negative integer at a finite index. In the second argument, checking four rows is insufficient: the sequence could occur later. We must use an arbitrary index \(k\) and show a difference at position \(k\), covering every row.
