Relations — Trick Questions for Students

Part I — Trick Questions by Section

Definition of Relations

  1. Is every relation from \(X\) to \(Y\) a function?
    No. A relation is any subset of \(X \times Y\); a function requires each \(x\) to have exactly one \(y\). E.g., on \(\mathbb{Z}\), \(<\) is a relation but not a function.
  2. Can a relation be empty? Can it be all of \(X \times Y\)?
    Yes to both. The empty set is a valid subset of \(X \times Y\) (no elements relate), and \(X \times Y\) itself is the "universal relation." Both are perfectly legal relations.
  3. If \(R\) is a relation on \(X\), is \(X\) necessarily the set of all first coordinates that actually appear?
    No! The domain is the declared set \(X\), not the set of first coordinates present in \(R\). See the full elaboration in Part II below.

Properties of Relations

  1. Is the empty relation on a nonempty set reflexive? Symmetric? Transitive?
    Not reflexive (unless \(X = \emptyset\)); vacuously symmetric and vacuously transitive. This is a great one because students often say "symmetric" is false since "nothing relates," but the implication is vacuously true.
  2. Can a relation be both symmetric and antisymmetric? Give an example.
    Yes: equality \(=\) on any set. Also any relation where \(xRy\) only when \(x = y\). Trick: students often think these are opposites.
  3. Is \(<\) on \(\mathbb{Z}\) symmetric? Is \(\le\) asymmetric?
    \(<\) is not symmetric; \(\le\) is not asymmetric (because \(x \le x\)). The antisymmetric/asymmetric distinction is worth quizzing directly.
  4. If \(R\) is symmetric and transitive, must it be reflexive?
    Almost — but not quite. If every element relates to something, then symmetry + transitivity gives reflexivity on that element. But an element related to nothing breaks it. Example: on \(X = \{1,2,3\}\), \(R = \{(1,2),(2,1),(1,1),(2,2)\}\) is symmetric and transitive but not reflexive (3 is isolated). Great "gotcha."
  5. Is "\(x\) and \(y\) are siblings" reflexive if we allow a person to be their own sibling by some definition?
    The notes say no; but push students: the answer depends on the definition of "sibling." Usually "distinct people sharing a parent," so not reflexive. The point: relation properties depend on precise definitions.
  6. Rock-paper-scissors: is it antisymmetric? Asymmetric?
    It's asymmetric (if \(x\) beats \(y\), \(y\) doesn't beat \(x\)) and hence antisymmetric (vacuously — the antecedent \(xRy \land yRx\) is never true). Students often miss the vacuous antisymmetry.
  7. Is "divides" on \(\mathbb{Z}\) antisymmetric?
    Careful: on \(\mathbb{Z}\), \(2 \mid -2\) and \(-2 \mid 2\) but \(2 \neq -2\), so not antisymmetric on \(\mathbb{Z}\). It is antisymmetric on \(\mathbb{N}\). Excellent trap if students assume it's like \(\le\).
  8. Is "\(x\) is no younger than \(y\)" the same as "\(x\) is at least as old as \(y\)"?
    Yes, and it's reflexive. But watch: "no younger than" is \(\ge\) on age, which is reflexive, antisymmetric, transitive — a partial order, not an equivalence. Good segue to distinguish equivalence vs. order.

Equivalence Relations

  1. Is "\(x \le y\)" an equivalence relation? Which property fails?
    Reflexive and transitive, but not symmetric. Good sanity check.
  2. Can an equivalence relation have exactly one equivalence class? Exactly \(|X|\) classes?
    Yes: the universal relation \(X \times X\) gives one class; equality gives \(|X|\) singleton classes. These are the two extremes.
  3. If \(x \sim y\) and \(y \sim z\), do we need transitivity to conclude \(x \sim z\)? What if the relation isn't transitive — give a concrete failure.
    Rock-paper-scissors: rock ~ scissors, scissors ~ paper, but not rock ~ paper. Nice callback.

Function-Induced Equivalence Relations

  1. Is every equivalence relation induced by some function?
    Yes! Given \(\sim\), define \(f(x) = [x]_\sim\) (the equivalence class). Then \(f(x) = f(y) \iff x \sim y\). So the theorem's converse holds. This is a beautiful "trick" — students think the theorem only goes one way. (Caveat: the codomain is the quotient set, which is fine.)
  2. For \(f(x) = x^2\) on \(\mathbb{Z}\): is \(x \sim y \iff x^2 = y^2\) the same as \(x = \pm y\)? What are the classes?
    Yes; classes are \(\{n, -n\}\) for \(n > 0\), and \(\{0\}\). Ask: "How many classes?" — countably infinite, one per nonnegative integer.
  3. For \(f(x) = \sin x\): is \([\pi/2] = [5\pi/2]\)? Is \([\pi/2] = [-\pi/2]\)?
    First yes (\(\sin\) equal), second no (\(\sin(\pi/2)=1 \neq -1 = \sin(-\pi/2)\)). Students often conflate symmetry of sine with equality of values.
  4. For \(f(n) = \lfloor n/2 \rfloor\) on \(\mathbb{N}\): what is \([1]\)? Is it \(\{0,1\}\) or \(\{1,2\}\)?
    \([1] = \{0,1\}\) since \(\lfloor 1/2 \rfloor = 0 = \lfloor 0/2 \rfloor\). The clean way to see it is \([2k] = \{2k, 2k+1\}\). Trick: ask about \([3]\) — students may guess \(\{3,4\}\), but it's \(\{6,7\}\).
  5. Can two different functions induce the same equivalence relation?
    Yes: \(f(x) = x^2\) and \(g(x) = |x|\) on \(\mathbb{Z}\) induce the same \(\sim\). The relation only sees the fibers of the function, not the codomain values.

Equivalence Classes

  1. Is \([x]\) ever empty?
    No, because \(x \in [x]\) by reflexivity. Quick check that students internalize reflexivity's role.
  2. Can \([x] = [y]\) even when \(x \neq y\)? Can \([x] \cap [y] \neq \emptyset\) with \([x] \neq [y]\)?
    First yes (e.g., \([1]=[-1]\) for squares); second no — classes are either identical or disjoint. This is the key lemma for partitions.
  3. For congruence mod 10, is \([-3] = [7]\)? What's a "good" set of representatives?
    Yes, \(-3 \equiv 7 \pmod{10}\). Representatives: \(\{0,1,\ldots,9\}\), but also \(\{-5,\ldots,4\}\), etc. Ask: "Is \(\{0, 10, 20, \ldots\}\) a set of representatives?" — No, it misses classes.
  4. How many equivalence classes does \(\equiv \pmod{0}\) have?
    Trick! Mod 0 is undefined/usually means equality \(x = y\), giving infinitely many singleton classes. Or if defined as \(x - y\) divisible by 0, only \(x = y\) works. Good discussion of definitions.

Partitions

  1. Is \(\{\emptyset, \{1,2\}, \{3\}\}\) a partition of \(\{1,2,3\}\)?
    No: parts must be nonempty, and \(\emptyset\) is a part here. Also it doesn't cover anything extra but violates nonemptiness.
  2. Is \(\{\{1,2\}, \{2,3\}\}\) a partition of \(\{1,2,3\}\)?
    No: parts overlap at 2, and 2 lies in two parts. Fails disjointness.
  3. Can a partition have infinitely many parts? Can a part be infinite?
    Yes to both: \(\mathbb{Z}\) partitioned into \(\{\{n\}: n \in \mathbb{Z}\}\) (infinitely many finite parts); or into evens/odds (finitely many infinite parts); or \(\mathbb{R}\) into cosets of \(\mathbb{Z}\) (infinitely many infinite parts).
  4. Given the partition \(\{\{a\},\{b,d\},\{c\}\}\) of \(\{a,b,c,d\}\): is \(a \sim c\)? Is \(b \sim d\)? Is \(d \sim b\)?
    No, yes, yes. Checks that "same part" is symmetric and that different parts mean not related.
  5. The notes say equivalence relations and partitions are "the same data." Is the correspondence a bijection? What maps to what?
    Yes: relation \(\mapsto\) its set of classes; partition \(\mapsto\) "same part" relation. These are mutually inverse. A conceptual "trick" worth stating explicitly.

Cross-Cutting "Gotcha" Questions

  1. Give a relation that is reflexive and symmetric but not transitive.
    E.g., on \(\{1,2,3\}\): \(\{(1,1),(2,2),(3,3),(1,2),(2,1),(2,3),(3,2)\}\) — 1~2 and 2~3 but not 1~3. Classic.
  2. Give a relation that is symmetric and transitive but not reflexive.
    The isolated-element example from #7. Students almost always forget this is possible.
  3. Give a relation that is reflexive and transitive but not symmetric.
    \(\le\) on \(\mathbb{Z}\). Easy, but good to have all three "two-out-of-three" examples side by side.
  4. True or false: if \(R\) is antisymmetric, then \(R\) is not symmetric.
    False: \(=\) is both. Antisymmetric and symmetric can coexist (only when \(xRy \Rightarrow x=y\)).
  5. True or false: a relation can be neither symmetric nor antisymmetric.
    True: e.g., on \(\{1,2,3\}\), \(R = \{(1,2),(2,1),(2,3)\}\): symmetric fails (2,3 but not 3,2); antisymmetric fails (1,2 and 2,1 but \(1 \neq 2\)).
Highest-value traps: #4, #7, #10, #15, #21, and #30 — they target the misconceptions students most reliably carry into exams.

Part II — Elaboration on Question 3

"If \(R\) is a relation on \(X\), is \(X\) necessarily the set of all first coordinates that actually appear?"

Short answer: No. This is a subtle but important point about what "a relation on \(X\)" actually means.

The precise definition

Recall the definition from the lecture:

A binary relation \(R\) from \(X\) to \(Y\) is a subset of \(X \times Y\).

So a relation on \(X\) is a subset of \(X \times X\). The set \(X\) is part of the declaration — it's the ambient set we're working in. It is not defined as "the set of things that actually appear as first coordinates."

There are two different sets students often conflate:

  • The declared set \(X\) — the universe the relation lives on. Fixed in advance.
  • The actual domain of \(R\) — \(\operatorname{dom}(R) = \{x \in X : \exists y,\; xRy\}\), i.e., the elements that actually relate to something.

These need not be equal. In general \(\operatorname{dom}(R) \subseteq X\), and the inclusion can be strict.

A concrete example

Let \(X = \{1, 2, 3\}\) and let

\[ R = \{(1,1)\}. \]

Is \(R\) a relation on \(X\)? Yes — it's a subset of \(X \times X = \{(1,1),(1,2),\ldots,(3,3)\}\), so it qualifies.

But:

  • The first coordinates that appear are just \(\{1\}\).
  • The element \(2\) never appears (as a first or second coordinate).
  • The element \(3\) never appears.

Yet \(R\) is still perfectly valid as "a relation on \(X = \{1,2,3\}\)." The set \(X\) is the stage; \(R\) is just one pattern of arrows drawn on that stage — possibly leaving some actors idle.

Why students get this wrong

The confusion comes from three places:

  1. The word "domain." In the lecture, \(X\) is called the domain of \(R\). But in other contexts (and in the "actual domain" sense above), "domain" means "the set of first coordinates that occur." These are different notions:
    • The declared domain is \(X\) (fixed by the setup).
    • The active domain / field is the set of elements actually involved in some pair.
    This is a genuine terminology collision, and it's worth flagging explicitly.
  2. Functions set a bad precedent. For a function \(f : X \to Y\), every \(x \in X\) must be assigned a value — so the domain is exactly the set of inputs. Students carry this intuition over to relations, but relations are laxer: an element of \(X\) may relate to nothing at all.
  3. Textbook pictures. Arrow diagrams usually draw an arrow from every element, so students assume every element participates. In fact, isolated vertices (elements related to nothing) are allowed and common.

Why it matters (where the trap bites)

This distinction is not pedantry — it changes answers to real questions:

Reflexivity

Consider \(R = \{(1,1)\}\) on \(X = \{1,2,3\}\).

  • If "on \(X\)" means the declared set \(\{1,2,3\}\): \(R\) is not reflexive, because \(2 \not\sim 2\) and \(3 \not\sim 3\).
  • If you mistakenly took the "domain" to be \(\{1\}\): you'd wrongly conclude \(R\) is reflexive (since \(1 \sim 1\)).

So the answer to "is \(R\) reflexive?" depends entirely on which set you're quantifying over. Reflexivity is \(\forall x \in X,\; xRx\) — and that \(\forall x \in X\) ranges over the whole declared set, including elements that never appear in any pair.

The "symmetric + transitive \(\Rightarrow\) reflexive" near-miss (Question 7)

This is exactly the same phenomenon. On \(X = \{1,2,3\}\),

\[ R = \{(1,2),(2,1),(1,1),(2,2)\} \]

is symmetric and transitive, but not reflexive — because \(3\) is isolated. If you silently shrank the universe to \(\{1,2\}\), it would be reflexive. The element \(3\) "does nothing" in \(R\), but it still counts when we check reflexivity, because reflexivity is a statement about all of \(X\).

Empty relation

The empty relation \(\varnothing \subseteq X \times X\) is a relation on any \(X\). Its "active domain" is empty — but it's still a relation on \(X\), and it's not reflexive unless \(X = \varnothing\). Again: the declared set governs.

How to phrase the correction to students

A clean way to say it:

"When we say \(R\) is a relation on \(X\), the \(X\) is not derived from \(R\) — it's given. \(R\) is a subset of \(X \times X\), full stop. Some elements of \(X\) may relate to nothing; that's allowed. When you check reflexivity, symmetry, transitivity, you always quantify over all of \(X\), not just the elements that happen to appear in \(R\)."

A useful diagnostic question to hand back to them:

"I give you \(X = \{1,2,3,4\}\) and \(R = \{(1,1),(2,2)\}\). Is \(R\) reflexive? Is it symmetric? Is it transitive?"

— Not reflexive (3 and 4 fail), symmetric, transitive. If a student says "reflexive," they've collapsed the declared set into the active domain.

One-line summary. A relation on \(X\) is a subset of \(X \times X\); \(X\) is fixed in advance and may contain elements that the relation never touches. Reflexivity (and every other property) quantifies over all of \(X\), so "which set is \(X\)?" is always part of the question — never infer \(X\) from the pairs you see.

Part III — Quick Reference: The "Two-out-of-Three" Relations

These are the standard examples students should be able to produce on demand. Having them side by side makes the independence of the properties vivid.

Relation Reflexive? Symmetric? Transitive?
\(=\) on any set Yes Yes Yes
\(\le\) on \(\mathbb{Z}\) Yes No Yes
\(<\) on \(\mathbb{Z}\) No No Yes
Reflexive + symmetric, not transitive (e.g., \(\{(1,1),(2,2),(3,3),(1,2),(2,1),(2,3),(3,2)\}\)) Yes Yes No
Symmetric + transitive, not reflexive (e.g., \(\{(1,2),(2,1),(1,1),(2,2)\}\) on \(\{1,2,3\}\)) No Yes Yes
Reflexive + transitive, not symmetric (\(\le\)) Yes No Yes
Rock-paper-scissors No No No
Empty relation on nonempty \(X\) No Yes (vacuous) Yes (vacuous)
