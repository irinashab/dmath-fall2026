A function assigns exactly one output to each input. Today we make that familiar idea precise, use quantifiers to guide proofs, and see how a function can help us count.

1. Begin with subsets

Let \(A=\{a,b,c\}\). List all subsets of \(A\), organized by size.

  1. How many subsets have zero, one, two, or three elements?
  2. How do you know your list is complete?
  3. Explain why \(X\subseteq A\) and \(X\in\mathcal P(A)\) mean the same thing.
Show solution
  • Zero elements: \(\emptyset\).
  • One element: \(\{a\},\{b\},\{c\}\).
  • Two elements: \(\{a,b\},\{a,c\},\{b,c\}\).
  • Three elements: \(\{a,b,c\}\).

There are eight subsets. Every subset has one of these four sizes, and the list includes all possibilities of each size. By definition, the elements of \(\mathcal P(A)\) are precisely the subsets of \(A\).

Keep the question of completeness in mind. Later we will describe a systematic way to encode every subset.

2. Ordered pairs and Cartesian products

Sets do not record order, but sometimes order matters:

\[\{0,1\}=\{1,0\},\qquad (0,1)\ne(1,0).\]

In an ordered pair, the first and second positions have different roles. Two ordered pairs are equal exactly when their corresponding entries agree:

\[(a,b)=(c,d)\iff(a=c\land b=d).\]

More generally, we can use ordered triples and ordered \(n\)-tuples. Entries may repeat: \((0,1,0)\) is an ordered triple.

The Cartesian product of two sets is

\[A\times B=\{(a,b):a\in A\text{ and }b\in B\}.\]

For example, \(\mathbb R\times\mathbb R\) is the usual coordinate plane. We write \(A^2\) for \(A\times A\).

List a small product

Let \(A=\{0,1\}\) and \(B=\{a,b,c\}\). List \(A\times B\). How does the product rule explain its size?

Show solution\[A\times B=\{(0,a),(0,b),(0,c),(1,a),(1,b),(1,c)\}.\]

There are two choices for the first entry and three for the second, so there are \(2\cdot3=6\) ordered pairs.

A relation from \(A\) to \(B\) is any subset of \(A\times B\). For instance, \(\{(x,y)\in\mathbb Z^2:x\le y\}\) is a relation on the integers. A relation can pair an input with several outputs, or with none. A function satisfies an additional requirement.

3. What makes a relation a function?

A function \(f:A\to B\) consists of a specified domain \(A\), a specified codomain \(B\), and a graph \(G\subseteq A\times B\) assigning exactly one output to each input:

\[\forall a\in A\;\exists!b\in B:\ (a,b)\in G.\]

The symbol \(\exists!\) means “there exists exactly one.” It combines two requirements:

  • Existence: each input in \(A\) has an output in \(B\).
  • Uniqueness: each input has only one output.

We write \(f(a)=b\) instead of \((a,b)\in G\). Different inputs are allowed to have the same output.

Which requirement fails?

Use domain \(\{0,1\}\) and codomain \(\{a,b,c\}\). Which graphs define functions?

\[G_1=\{(0,a),(0,b),(1,c)\},\]\[G_2=\{(0,a)\},\qquad G_3=\{(0,a),(1,a)\}.\]
Show solution
  1. \(G_1\) fails uniqueness: input 0 has two different outputs.
  2. \(G_2\) fails existence: input 1 has no output.
  3. \(G_3\) is a function: each input has exactly one output. Sharing the output \(a\) is allowed.

If we change the domain to \(\{0\}\), then \(G_2\) does define a function to \(\{a,b,c\}\).

The familiar vertical-line test checks that each input has at most one output. For a specified domain, we must also check that every input has an output.

Domain, codomain, and image

The domain and codomain are part of the function specification. A formula alone does not tell us all of this information.

For example, the rules \(f(n)=n\) and \(g(n)=n\), with

\[f:\mathbb N\to\mathbb N,\qquad g:\mathbb N\to\mathbb Z,\]

have the same graph, but different specified codomains. We treat them as different functions in this course.

The image of an input \(x\) is \(f(x)\). If \(X\subseteq A\), the image of \(X\) is

\[f(X)=\{f(x):x\in X\}.\]

The image of the whole domain, \(f(A)\), is the set of outputs actually attained. Always \(f(A)\subseteq B\); equality need not hold.

A quick counting question

How many functions are there from \(\{0,1\}\) to \(\{a,b,c\}\)?

Show solution

There are three choices for the output of 0 and three independent choices for the output of 1. Thus there are \(3^2=9\) functions. The choices may be equal.

4. Injectivity

A function is injective, or one-to-one, if different inputs always have different outputs. Equivalently, equal outputs force equal inputs:

\[\forall u,v\in A,\quad f(u)=f(v)\rightarrow u=v.\]

By contraposition, this is equivalent to

\[\forall u,v\in A,\quad u\ne v\rightarrow f(u)\ne f(v).\]

Negate the definition

What would demonstrate that a function is not injective?

Show solution\[\exists u,v\in A:\quad u\ne v\land f(u)=f(v).\]

Find two distinct inputs with the same output. Both inputs must belong to the domain.

Squaring on two different domains

Consider \(f:\mathbb Z\to\mathbb Z\), \(f(n)=n^2\). It is not injective: \(1\ne-1\), but \(f(1)=f(-1)=1\).

Now consider \(g:\mathbb N\to\mathbb N\), \(g(n)=n^2\). Recall that \(\mathbb N=\{0,1,2,\ldots\}\).

Prove that \(g\) is injective. Start with arbitrary \(m,n\in\mathbb N\) and assume \(g(m)=g(n)\). What must you conclude?

Show solution

We have \(m^2=n^2\), so \[(m-n)(m+n)=0.\]Either \(m-n=0\), giving \(m=n\), or \(m+n=0\). Since both numbers are nonnegative, the second possibility gives \(m=n=0\). In either case \(m=n\), so \(g\) is injective.

A few different outputs do not prove injectivity. A proof must cover arbitrary inputs; one pair of distinct inputs sharing an output disproves it.

5. Surjectivity

A function \(f:A\to B\) is surjective, or onto, if every element of its codomain is attained:

\[\forall y\in B\;\exists x\in A:\ f(x)=y.\]

Equivalently, \(f(A)=B\). The input \(x\) may depend on the target \(y\).

Negate the definition

Complete: “There is a target in the codomain such that…”

Show solution\[\exists y\in B\;\forall x\in A:\ f(x)\ne y.\]

To disprove surjectivity, give one target and show that no input maps to it. One unsuccessful choice of input is not enough.

Find the gap in this argument

Let \(f:\mathbb Z\to\mathbb Z\) be \(f(n)=2n\). A student writes:

Given \(y\in\mathbb Z\), choose \(n=y/2\). Then \(f(n)=y\), so \(f\) is onto.

  1. What has the student failed to check?
  2. Find a target that exposes the problem.
  3. Explain why no valid input maps to that target.
Show solution

The proposed input \(y/2\) need not be an integer. Choose \(y=1\). If \(2n=1\), then \(n=1/2\notin\mathbb Z\). Thus 1 has no preimage in the domain, and \(f\) is not onto.

Repair the codomain

Let \(2\mathbb Z=\{2k:k\in\mathbb Z\}\). Define \(g:\mathbb Z\to2\mathbb Z\) by \(g(n)=2n\). Prove that \(g\) is onto.

Show solution

Let \(y\in2\mathbb Z\) be arbitrary. By definition, \(y=2k\) for some \(k\in\mathbb Z\). This integer is a valid input, and \(g(k)=2k=y\). Therefore \(g\) is surjective.

Solving an equation gives a candidate input. Completing the proof requires checking that the candidate belongs to the domain.

Return to squaring

Let \(S=\{n^2:n\in\mathbb N\}\), including zero. Compare the rule \(n\mapsto n^2\) as a function \(\mathbb N\to\mathbb N\) and as a function \(\mathbb N\to S\). Which is injective? Which is surjective?

Show solution

Both are injective by the earlier argument. The first is not surjective: no natural number has square 2. Indeed, the squares of 0 and 1 are 0 and 1, and the square of any natural number at least 2 is at least 4.

The second is surjective: if \(s\in S\), then \(s=n^2\) for some \(n\in\mathbb N\), and that input maps to \(s\).

6. Bijections and counting subsets

A bijection is a function that is both injective and surjective. We also call it a one-to-one correspondence.

For finite sets, a bijection pairs every input with a different output and reaches every target. Therefore the two sets have the same number of elements.

Conversely, if two finite sets have the same number of elements, list their elements and pair the first with the first, the second with the second, and so on. This gives a bijection. If both sets are empty, the empty graph gives the bijection.

Encode a subset with three bits

Return to \(A=\{a,b,c\}\). A binary string of length three is an ordered triple with each entry either 0 or 1. We write these strings compactly as 000, 001, and so on. The set of all such strings is \(\{0,1\}^3\).

Fix the coordinate order \(a,b,c\). A 1 means “include this element”; a 0 means “leave it out.” Define

\[F:\{0,1\}^3\to\mathcal P(A).\]

For instance, \(F(011)=\{b,c\}\). The first bit excludes \(a\), and the other two include \(b\) and \(c\).

Before opening the table, find \(F(000)\), \(F(101)\), and the string that maps to \(\{a,b\}\).

Show the complete correspondence

Why is this a bijection?

  1. Why does each string describe exactly one subset?
  2. Why must different strings describe different subsets?
  3. Given an arbitrary subset \(X\subseteq A\), how can you construct a string that maps to it?
Show solution

Function: each bit fixes whether its corresponding element is included, determining exactly one subset.

Injective: two different strings differ in some coordinate. The corresponding element belongs to one output subset and not the other, so the output subsets differ.

Surjective: let \(X\subseteq A\). Write 1 in the first position if \(a\in X\), and 0 otherwise. Do the same for \(b\) and \(c\). The resulting string maps to exactly \(X\).

Count the strings to count the subsets

There are two independent choices for each of three bits. By the product rule, there are \(2^3=8\) strings. The bijection therefore gives eight subsets.

For a finite set \(A\) with \(n\) elements, fix a listing of those elements and use one bit for each. The same argument gives

\[|\mathcal P(A)|=2^n.\]

Here \(|A|\) denotes the number of elements in a finite set \(A\). For \(n=0\), there is one string of length zero and one subset of the empty set, consistent with \(2^0=1\).

7. Afterthought proofs

Work independently first, then compare with a partner. Write an argument for each core problem before opening its solution. The extension is optional in class.

1. A function with a missing output

Let \(f:\mathbb Z\to\mathbb Z\) be \(f(n)=2n+1\).

  1. Prove that \(f\) is injective.
  2. Disprove that \(f\) is surjective.
Show hint

For injectivity, start with equal outputs for arbitrary integer inputs. For surjectivity, look for an integer that cannot be expressed as \(2n+1\) with an integer \(n\).

Show solution

If \(f(m)=f(n)\), then \(2m+1=2n+1\), so \(m=n\). Thus \(f\) is injective.

The target 0 is not attained. The equation \(2n+1=0\) would require \(n=-1/2\), which is not an integer. Thus \(f\) is not surjective.

2. Change the codomain

Let \(O=\{2k+1:k\in\mathbb Z\}\), the set of odd integers. Define \(g:\mathbb Z\to O\) by \(g(n)=2n+1\). Prove that \(g\) is a bijection. You may reuse your injectivity argument.

Show hint

Let \(y\in O\). What does the definition of \(O\) tell you? Use it to find a valid input.

Show solution

Each integer input gives exactly one odd integer output, so the rule defines a function with the specified domain and codomain. Injectivity follows from the same algebra as in Problem 1.

Let \(y\in O\). There is an integer \(k\) such that \(y=2k+1\). Then \(g(k)=y\). Thus \(g\) is surjective, and hence bijective.

Extension. Equal images under an injection

Suppose \(f:A\to B\) is injective and \(X,Y\subseteq A\). Prove

\[f(X)=f(Y)\rightarrow X=Y.\]
Show hint

Let \(x\in X\). Since \(f(x)\in f(Y)\), there is some \(y\in Y\) with \(f(x)=f(y)\). What does injectivity tell you?

Show solution

Assume \(f(X)=f(Y)\). Let \(x\in X\). Then \(f(x)\in f(Y)\), so there exists \(y\in Y\) with \(f(x)=f(y)\). Injectivity gives \(x=y\), so \(x\in Y\). Thus \(X\subseteq Y\).

Conversely, let \(y\in Y\). Since \(f(y)\in f(X)\), there is \(x\in X\) with \(f(y)=f(x)\). Injectivity gives \(y=x\), so \(y\in X\). Thus \(Y\subseteq X\), and therefore \(X=Y\).

Before the closing preview

Let \(h:\mathbb Z\to\mathbb Z\) be \(h(n)=n+1\). Prove that it is injective and surjective. In your surjectivity proof, explicitly check that your chosen input is an integer.

Review after writing your proof

If \(h(m)=h(n)\), then \(m+1=n+1\), giving \(m=n\). Thus \(h\) is injective.

Given \(y\in\mathbb Z\), choose \(n=y-1\in\mathbb Z\). Then \(h(n)=(y-1)+1=y\). Thus \(h\) is surjective.

8. A preview of infinite cardinality

For finite sets, bijections capture the idea of having the same number of elements. We use this to define equal cardinality for sets that may be infinite:

\[|A|=|B|\quad\text{if and only if there is a bijection }f:A\to B.\]

Let \(2\mathbb N=\{2n:n\in\mathbb N\}\), the set of even natural numbers. Consider

\[f:\mathbb N\to2\mathbb N,\qquad f(n)=2n.\]

Our earlier doubling argument shows that this function is bijective. Can you identify the injectivity and surjectivity steps?

Show solution

If \(2m=2n\), then \(m=n\), so \(f\) is injective. If \(y\in2\mathbb N\), then \(y=2k\) for some \(k\in\mathbb N\), and \(f(k)=y\), so \(f\) is surjective.

Consequently, \(|\mathbb N|=|2\mathbb N|\), even though \(2\mathbb N\) is a proper subset of \(\mathbb N\): it leaves out every odd natural number.

This is surprising, but it is not a logical contradiction. Being a proper subset and having smaller cardinality are different claims for infinite sets. We will explore that distinction further.
