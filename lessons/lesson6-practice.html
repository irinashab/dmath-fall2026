Lesson 6: Post-Lesson Exercises

These exercises review countability, bijections, and Cantor’s diagonal argument. Attempt each problem before opening the solution. Write full sentences in your proofs, and state clearly which function or construction you are using.

  1. Warm-up: countability of a subset
  2. Bijection from a finite set plus \(\mathbb N\)
  3. Countable union of finite sets
  4. An injection that is not a bijection
  5. Diagonal argument with ternary digits
  6. The set of all functions \(\mathbb N\to\{0,1,2\}\)
  7. Challenge: algebraic numbers are countable

1. Warm-up: countability of a subset

Let \(A=\{n\in\mathbb N:n\text{ is a perfect square}\}=\{0,1,4,9,16,\ldots\}\).

  1. Write down an explicit bijection \(f:\mathbb N\to A\).
  2. Conclude that \(|A|=\aleph_0\).
Show solution

(1) Define \(f(n)=n^2\). This maps \(\mathbb N\) to \(A\), since every natural number squares to a perfect square, and every perfect square is of the form \(n^2\) for a unique \(n\in\mathbb N\).

(2) The function \(f\) is injective: if \(n^2=m^2\) with \(n,m\ge0\), then \(n=m\). It is surjective by definition of \(A\). Hence \(f\) is a bijection, so \(|A|=|\mathbb N|=\aleph_0\).

2. Bijection from a finite set plus \(\mathbb N\)

Let \(S=\{a,b,c\}\cup\mathbb N\), where \(a,b,c\) are three distinct objects not in \(\mathbb N\). Show that \(S\) is countably infinite by constructing an explicit bijection \(f:\mathbb N\to S\).

Show hint

Send the first three natural numbers to \(a,b,c\), then shift the remaining natural numbers by 3.

Show solution

Define

\[ f(n)=\begin{cases} a,&n=0,\\ b,&n=1,\\ c,&n=2,\\ n-3,&n\ge3. \end{cases} \]

Injective. The values \(a,b,c\) are distinct and not in \(\mathbb N\), so they cannot equal any \(n-3\). For \(n,m\ge3\), \(n-3=m-3\) implies \(n=m\).

Surjective. Every element of \(\{a,b,c\}\) is hit by \(0,1,2\). Every natural number \(k\in\mathbb N\) is hit by \(n=k+3\).

Thus \(f\) is a bijection, so \(|S|=\aleph_0\).

3. Countable union of finite sets

For each \(n\in\mathbb N\), let \(A_n=\{0,1,2,\ldots,n\}\), so each \(A_n\) is finite. Show that

\[ S=\bigcup_{n=0}^{\infty}A_n \]

is countably infinite by finding a bijection \(\mathbb N\to S\).

Show hint

What is \(S\) as a set? It is just \(\mathbb N\) itself.

Show solution

Since \(A_n\subseteq\mathbb N\) for every \(n\), we have \(S\subseteq\mathbb N\). Conversely, for any \(k\in\mathbb N\), \(k\in A_k\), so \(\mathbb N\subseteq S\). Hence \(S=\mathbb N\), and the identity function \(\mathrm{id}_{\mathbb N}:\mathbb N\to S\) is a bijection. Therefore \(|S|=\aleph_0\).

Remark. This is a degenerate case of the countable-union theorem: the union of countably many finite sets can be finite or countably infinite, never uncountable.

4. An injection that is not a bijection

Define \(f:\mathbb N\to\mathbb N\) by \(f(n)=2n\).

  1. Show that \(f\) is injective but not surjective.
  2. Does this contradict the statement “a set is countably infinite if there is a bijection from \(\mathbb N\) to it”? Explain.
Show solution

(1) If \(2n=2m\), then \(n=m\), so \(f\) is injective. But \(1\in\mathbb N\) has no preimage: \(2n=1\) has no natural-number solution. So \(f\) is not surjective.

(2) No contradiction. The definition requires some bijection \(\mathbb N\to A\), not that every injection is a bijection. Here \(2\mathbb N\) is countably infinite via the bijection \(n\mapsto2n\) from \(\mathbb N\) to \(2\mathbb N\), viewed with codomain \(2\mathbb N\) rather than \(\mathbb N\).

This exercise highlights the difference between an injection \(A\to B\) and a bijection \(A\to B\): an injection only shows \(|A|\le|B|\), not \(|A|=|B|\).

5. Diagonal argument with ternary digits

Let \(T\) be the set of infinite sequences \(s:\mathbb N\to\{0,1,2\}\) (ternary sequences). Suppose \(s_0,s_1,s_2,\ldots\) is any proposed list of elements of \(T\). Define \(t\) by

\[ t(n)=\begin{cases} 0,&s_n(n)=1,\\ 1,&s_n(n)\ne1. \end{cases} \]
  1. Show that \(t\in T\).
  2. Show that \(t\ne s_k\) for every \(k\in\mathbb N\).
  3. Conclude that \(T\) is uncountable.
Show solution

(1) Each \(t(n)\) is 0 or 1, hence lies in \(\{0,1,2\}\). So \(t\in T\).

(2) Fix \(k\in\mathbb N\). At position \(k\), \(t(k)\) is defined by flipping the value \(s_k(k)\): if \(s_k(k)=1\), then \(t(k)=0\ne1\); if \(s_k(k)\ne1\), then \(t(k)=1\ne s_k(k)\). In either case \(t(k)\ne s_k(k)\), so the sequences differ at position \(k\). Hence \(t\ne s_k\).

(3) Since \(k\) was arbitrary, \(t\) differs from every sequence in the list. The list misses \(t\), so no list covers \(T\). Therefore \(T\) is uncountable.

Remark. The same argument works for sequences over any alphabet with at least two symbols, using a rule that avoids the diagonal value.

6. The set of all functions \(\mathbb N\to\{0,1,2\}\)

Let \(F\) be the set of all functions \(f:\mathbb N\to\{0,1,2\}\).

  1. Explain why \(F\) is in bijection with the set \(T\) of ternary sequences from Exercise 5.
  2. Conclude that \(F\) is uncountable.
Show solution

(1) A function \(f:\mathbb N\to\{0,1,2\}\) is exactly the same data as the sequence \((f(0),f(1),f(2),\ldots)\) of its values. So the identity map on the underlying data is a bijection \(F\to T\).

(2) A set in bijection with an uncountable set is uncountable. Since \(T\) is uncountable by Exercise 5, \(F\) is uncountable.

Remark. More generally, the set of all functions \(\mathbb N\to A\) is uncountable whenever \(A\) has at least two elements, by the same diagonal argument.

7. Challenge: algebraic numbers are countable

A real number \(x\) is algebraic if there exist integers \(a_0,a_1,\ldots,a_n\), not all zero, with \(a_n\ne0\), such that

\[ a_nx^n+a_{n-1}x^{n-1}+\cdots+a_1x+a_0=0. \]

Let \(\mathbb A\) be the set of algebraic real numbers. Show that \(\mathbb A\) is countable.

Show hint

A polynomial of degree \(n\) has at most \(n\) real roots. Count the polynomials first: each polynomial is determined by a finite tuple of integers \((a_0,\ldots,a_n)\) with \(a_n\ne0\). Use the countability of finite tuples of integers and the countable-union theorem.

Show solution

Step 1: Count the polynomials. For each \(n\ge1\), let \(P_n\) be the set of polynomials of degree exactly \(n\) with integer coefficients:

\[ P_n=\{a_nx^n+\cdots+a_0:a_n\ne0,\ a_i\in\mathbb Z\}. \]

The map \(P_n\to\mathbb Z^{n+1}\) sending a polynomial to its coefficient tuple is a bijection. Since \(\mathbb Z\) is countable and finite products of countable sets are countable, \(\mathbb Z^{n+1}\) is countable. Hence \(P_n\) is countable for each \(n\).

Step 2: Count all polynomials. The set of all nonconstant integer polynomials is

\[ P=\bigcup_{n=1}^{\infty}P_n. \]

By the countable-union theorem (Exercise A of the lesson), \(P\) is countable.

Step 3: Count the roots. For each polynomial \(p\in P\), let \(R(p)\) be its set of real roots. A polynomial of degree \(n\) has at most \(n\) real roots, so each \(R(p)\) is finite. The set of algebraic numbers is

\[ \mathbb A=\bigcup_{p\in P}R(p). \]

This is a countable union of finite sets. Indexing \(P\) as \(p_0,p_1,p_2,\ldots\), we can list \(\mathbb A\) by listing the roots of \(p_0\) first, then the new roots of \(p_1\), then the new roots of \(p_2\), and so on, removing duplicates. Each root is reached after finitely many steps, so \(\mathbb A\) is countable.

Remark. Since \(\mathbb R\) is uncountable and \(\mathbb A\) is countable, there must exist real numbers that are not algebraic. Such numbers are called transcendental. This argument shows they exist without exhibiting a single example.
