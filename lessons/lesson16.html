1. Seven bridges: what information matters?

The classic Königsberg problem asks whether a person can cross every bridge exactly once in a single continuous walk. The walk may start and end in different places. Travel within each land region is unrestricted; crossing the river requires a bridge.

Discuss before calculating

Does the length of a bridge matter? Does the shape of an island matter? What information must a mathematical model preserve?

Replace each land region by a vertex and each bridge by an edge. The essential information is which regions each bridge connects. Two different bridges may connect the same pair of regions, so we must keep them as different edges.

Euler showed in 1736 that the walk is impossible. We will discover the obstruction and return to this graph after developing the needed language.

2. Graphs, edges, and degrees

Throughout the main lesson, graphs are finite and undirected.

Two graph models

A simple graph is a pair \(G=(V,E)\), where \(V\) is the vertex set and \(E\) is a set of two-element subsets of \(V\). An edge \(\{u,v\}\) joins distinct vertices. There are no loops or parallel edges.

In an undirected multigraph, edges are distinct objects with assigned endpoints. Several edges may have the same endpoints. We also allow a loop, whose two endpoints coincide.

Vertices are adjacent if an edge joins them. An edge is incident to each of its endpoints. The placement of the vertices and the shapes of the drawn edges do not change the graph. Crossing lines do not create a vertex unless a vertex is explicitly marked.

The degree \(\deg(v)\) counts edge endpoints at \(v\). Each ordinary incident edge contributes 1; each loop contributes 2. A loop is still just one edge. Parallel edges each contribute separately. A vertex of degree 0 is isolated.

Your turn

Find the degree of each labeled vertex and the number of edges. Check each edge at both endpoints.

Check your count

In vertex order \(A,B,C,D,E\), the degrees are \((3,2,4,2,3)\). There are 7 edges. The sum is \(14\).

We list a degree sequence in nondecreasing order. For this graph it is \((2,2,3,3,4)\). A list in a specified vertex order is useful too, but need not be sorted.

Which degree sequences are possible?

For each list, draw a simple undirected graph with exactly those vertex degrees, or explain why none exists.

  1. \((1,1,2,2)\)
  2. \((1,1,1,2)\)
  3. \((2,2,2,2)\)
  4. \((0,1,2,3)\)
Solutions
  1. A path on four vertices works: \(a-b-c-d\).
  2. Impossible: the degree sum is 5, but each edge contributes 2 to that sum.
  3. A four-vertex cycle works: \(a-b-c-d-a\).
  4. Impossible: in a simple graph on four vertices, a degree-3 vertex must be adjacent to every other vertex, including the supposedly isolated one. Both the absence of loops and the absence of parallel edges matter.

Lesson: an even degree sum is necessary, but it is not sufficient for a list to be the degree sequence of a simple graph.

3. Count endpoints in two ways

Handshaking Lemma

For every finite undirected graph, including our multigraphs with loops,

\[\sum_{v\in V}\deg(v)=2|E|.\]

Proof. Count all edge endpoints. Summing vertex degrees counts them vertex by vertex. Counting edge by edge gives two endpoints per edge, including two at the same vertex for a loop. Both counts describe the same collection, so they are equal.

Parity consequence

Every finite undirected graph has an even number of odd-degree vertices.

Proof. The degree sum is even. Even-degree vertices contribute 0 modulo 2, and each odd-degree vertex contributes 1. Thus the number of odd-degree vertices is 0 modulo 2.

Quick check

Could a graph have exactly three odd-degree vertices? Could it have five vertices of degree 3?

Answer

Exactly three odd-degree vertices is impossible. A graph on exactly five vertices, all of degree 3, is also impossible: its degree sum would be 15. If five degree-3 vertices are only part of a larger graph, additional odd-degree vertices could make the total even.

4. Eulerian routes: use every edge

A small vocabulary for routes

  • A walk is an alternating sequence \(v_0,e_1,v_1,\ldots,e_k,v_k\), where each edge joins the vertices immediately before and after it. Vertices and edges may repeat. Specifying edges is essential when parallel edges exist.
  • A trail is a walk with no repeated edges.
  • A path is a walk with no repeated vertices.
  • A walk is closed if its starting and ending vertices coincide. A cycle is a nonempty closed trail with no repeated vertices except the first and last. In a simple graph, a cycle has at least three edges.

A graph is connected if a path joins every pair of vertices.

An Eulerian trail uses every edge exactly once. It may repeat vertices. It is open when its endpoints differ. An Eulerian circuit is a closed Eulerian trail. Some books call an Eulerian trail an “Eulerian path”; we use “trail” to distinguish it from a path with no repeated vertices.

Why odd degrees control the endpoints

At every intermediate visit to a vertex, arrival uses one edge endpoint and departure uses another. These endpoints pair up. An open trail leaves one unpaired departure at the start and one unpaired arrival at the end. Therefore its endpoints have odd degree, while every other vertex has even degree. In a closed trail, all endpoints pair up.

Eulerian theorem

Let \(G\) be a finite undirected graph with at least one edge, and suppose all vertices incident to edges lie in a single connected component.

  • \(G\) has an Eulerian circuit if and only if every vertex has even degree.
  • \(G\) has an open Eulerian trail if and only if exactly two vertices have odd degree. Those two vertices are its endpoints.
  • Consequently, \(G\) has an Eulerian trail, allowing a closed one, if and only if it has zero or two odd-degree vertices.

Isolated vertices do not affect an edge-covering route. For a graph with no edges and at least one vertex, the length-zero walk at that vertex uses all edges.

Why connectivity is needed. A cycle \(C_6\) and two disjoint triangles both have degree sequence \((2,2,2,2,2,2)\). Only the first has an Eulerian circuit: no walk can jump between the triangles.

Why the conditions are sufficient

First suppose every degree is even. Start at a vertex incident to an edge and keep following unused edges until none is available. You cannot get stuck at a different vertex: each arrival there leaves an unused departure, because its original degree is even. The resulting trail therefore closes at its starting vertex.

If unused edges remain, connectivity guarantees that some vertex on the closed trail is incident to an unused edge. Removing the used edges leaves every degree even, so build another closed trail from that vertex using unused edges. Splice this new trail into the first one. Repeat. Each step uses additional edges, and there are only finitely many, so eventually the closed trail uses every edge.

Now suppose exactly two vertices, \(s\) and \(t\), have odd degree. Add one extra edge joining them, permitting a parallel edge if necessary. All degrees become even, so the augmented graph has an Eulerian circuit. Delete the added edge and read the remaining circuit starting just after it: this gives an open Eulerian trail from one odd vertex to the other.

Return to Königsberg

The bridge multigraph has degrees \(3,3,3,5\). All four vertices have odd degree. An Eulerian trail can have at most two odd-degree vertices, so crossing each of the seven bridges exactly once is impossible, even if the walk ends somewhere different from where it starts.

Find a route

Return to the graph on \(A,B,C,D,E\). Does it have an Eulerian trail? A circuit? Find a route if possible.

Worked solution

The degrees in vertex order are \((3,2,4,2,3)\), with only \(A\) and \(E\) odd. The graph is connected, so it has an open Eulerian trail from \(A\) to \(E\), but no Eulerian circuit.

\[A\to B\to C\to A\to E\to C\to D\to E.\]

The seven edges used are \(AB,BC,CA,AE,EC,CD,DE\), each exactly once. Repeated vertices are allowed.

5. Hamiltonian routes: visit every vertex

A Hamiltonian path is a path that visits every vertex of the graph. A Hamiltonian cycle is a cycle that visits every vertex, returning to its start only at the end.

Two different route requirements
RequirementEulerian trailHamiltonian path
Must useEvery edge exactly onceEvery vertex exactly once
May repeat vertices?YesNo
Must use every edge?YesNo

For example, \(A-B-C-D-E\) is a Hamiltonian path in our seven-edge graph, and \(A-B-C-D-E-A\) is a Hamiltonian cycle. The earlier Eulerian trail repeats \(A\) and \(C\), so it is not a Hamiltonian path.

Neither condition implies the other

Explain why \(K_4\) has a Hamiltonian cycle but no Eulerian trail. Then consider two triangles sharing exactly one vertex: explain why this graph has an Eulerian circuit but no Hamiltonian cycle.

Explanation

In \(K_4\), all four degrees are 3, so there is no Eulerian trail, but visiting the four vertices in order and returning to the first gives a Hamiltonian cycle.

For the two triangles, the shared vertex has degree 4 and the others have degree 2. The graph is connected, so it has an Eulerian circuit. A cycle visiting both triangles would have to pass through the shared vertex more than once before closing, which is forbidden for a Hamiltonian cycle.

Optional enrichment: why the distinction matters in computing

Eulerian routes have an efficient construction based on unused edges and splicing closed trails. Deciding whether a general finite simple graph has a Hamiltonian path or cycle is NP-complete. No polynomial-time algorithm is known for either decision problem. This does not mean that particular graphs are always difficult, or that the two problems have been proved to require superpolynomial time.

6. Familiar families of graphs

Complete graphs

The complete graph \(K_n\) is the simple graph on \(n\) vertices with an edge between every pair of distinct vertices.

Count in two ways

How many edges does \(K_n\) have? Give one argument using pairs and another using degrees.

Two proofs

Every edge is a two-element subset of the vertices, so \(|E|=\binom n2=n(n-1)/2\). Alternatively, every vertex has degree \(n-1\), so the Handshaking Lemma gives \(2|E|=n(n-1)\). This is the maximum number of edges in any simple graph on \(n\) vertices.

Cycle graphs

For \(n\ge3\), the cycle graph \(C_n\) has vertices \(v_0,\ldots,v_{n-1}\) and edges joining consecutive vertices, including \(v_{n-1}\) to \(v_0\). Every vertex has degree 2, and there are \(n\) edges.

Bipartite graphs

A graph is bipartite if its vertex set can be partitioned as \(V=V_1\cup V_2\), with \(V_1\cap V_2=\varnothing\), so that every edge has one endpoint in each part. Think of coloring vertices with two colors so that adjacent vertices always have different colors.

The complete bipartite graph \(K_{n,m}\) has parts of sizes \(|V_1|=n\) and \(|V_2|=m\), with every possible edge between the parts and no edges within either part. It has \(nm\) edges.

When is a cycle bipartite?

Try \(C_3,C_4,C_5,C_6\). Make a conjecture about \(C_n\), and explain why it is true.

Proof

\(C_n\) is bipartite exactly when \(n\) is even. Along the cycle the colors must alternate. When \(n\) is even, put the even-indexed vertices in one part and the odd-indexed vertices in the other; every edge crosses between parts. When \(n\) is odd, the last vertex has the same color as the first, yet they are adjacent, a contradiction.

A bipartite graph need not be complete bipartite: \(C_6\) has 6 edges, whereas \(K_{3,3}\) has 9.

7. Exit questions

  1. A connected graph has degree sequence \((2,2,2,3,3)\). How many edges does it have? What kind of Eulerian route does it have?
  2. A connected graph has degree sequence \((2,2,4,4)\). Can an Eulerian trail start and end at different vertices?
  3. For which \(n\ge3\) does \(K_n\) have an Eulerian circuit?
  4. Is \(K_{3,5}\) Eulerian? Does it have a Hamiltonian cycle?
  5. Explain in one sentence why an even degree sum does not guarantee an Eulerian circuit.
Solutions and explanations
  1. The sum is 12, so there are 6 edges. Exactly two vertices have odd degree, so there is an open Eulerian trail, but no Eulerian circuit.
  2. No. All degrees are even, so it has an Eulerian circuit; any trail using all edges must close.
  3. Exactly when \(n\) is odd: every degree is \(n-1\), and \(K_n\) is connected.
  4. It has 15 edges. The three vertices in one part have degree 5, and the five in the other have degree 3: all eight are odd, so there is no Eulerian trail. There is no Hamiltonian cycle either, because any cycle in a bipartite graph alternates between parts and uses equally many vertices from each; these parts have unequal sizes.
  5. For example, two disjoint triangles have an even degree sum and all degrees even, but no single walk can cover both components. Also, an even degree sum alone does not require each degree to be even.
Looking ahead: directed and weighted graphs

In a directed graph, edges have a specified direction, from a start vertex to an end vertex. The in-degree counts incoming edges and the out-degree counts outgoing edges; a directed loop contributes 1 to each. Weighted graphs attach quantities, such as distance or travel time, to edges. These models are useful for route-finding, but the undirected Eulerian theorem above must not be applied to them without checking the relevant assumptions.
