Part I. Core problems

These problems build fluency with the definitions. Aim to finish them without looking at the hints.

C1. Bijection between finite sets

Let \(A=\{1,2,3\}\) and \(B=\{x,y,z\}\). Define \(f:A\to B\) by

\[f(1)=y,\quad f(2)=z,\quad f(3)=x.\]
  1. Prove that \(f\) is a bijection.
  2. Find \(f^{-1}\).
  3. Compute \(f^{-1}\circ f\) and \(f\circ f^{-1}\).
Show hint

For injectivity, check that the three outputs are distinct. For surjectivity, check that every element of \(B\) appears among the outputs.

Show solution

1. Injective: the outputs \(y,z,x\) are all distinct, so different inputs have different outputs. Surjective: the codomain is \(B=\{x,y,z\}\), and all three elements are attained: \(x=f(3)\), \(y=f(1)\), \(z=f(2)\). Hence \(f\) is bijective.

2. Reversing each pair gives \(f^{-1}(x)=3\), \(f^{-1}(y)=1\), \(f^{-1}(z)=2\).

3. \(f^{-1}\circ f\) is the identity on \(A\), and \(f\circ f^{-1}\) is the identity on \(B\).

C2. Image and preimage

Let \(f:\mathbb Z\to\mathbb Z\), \(f(n)=n^2\). Let \(X=\{-2,-1,0,1,2\}\) and \(Y=\{0,1,4\}\).

  1. Compute \(f(X)\).
  2. Compute the preimage \(f^{-1}(Y)=\{n\in\mathbb Z:f(n)\in Y\}\).
  3. Is \(f^{-1}(Y)\) the same as the inverse function applied to \(Y\)? Explain.
Show hint

For part 2, find every integer whose square lies in \(Y\). For part 3, recall that an inverse function exists only when the original function is a bijection.

Show solution

1. Squaring each element of \(X\) gives \(f(X)=\{0,1,4\}\).

2. We need all \(n\in\mathbb Z\) with \(n^2\in\{0,1,4\}\). These are \(n=0\), \(n=\pm 1\), and \(n=\pm 2\). So \(f^{-1}(Y)=\{-2,-1,0,1,2\}\).

3. No. The notation \(f^{-1}(Y)\) here denotes the preimage of the set \(Y\), which is defined for any function. The inverse function \(f^{-1}\) exists only when \(f\) is a bijection, and this \(f\) is neither injective (since \(f(1)=f(-1)\)) nor surjective (since no integer squares to 2). So \(f^{-1}(Y)\) is a set of inputs, not the result of applying an inverse function.

C3. Composition and injectivity

Let \(f:\mathbb R\to\mathbb R\), \(f(x)=2x+3\), and \(g:\mathbb R\to\mathbb R\), \(g(x)=x^2\).

  1. Compute \((g\circ f)(x)\) and \((f\circ g)(x)\).
  2. Is \(g\circ f\) injective? Prove or disprove.
  3. Is \(g\circ f\) surjective? Prove or disprove.
Show hint

For part 2, look for two distinct inputs that produce the same squared output. For part 3, ask what values a square can take.

Show solution

1. \((g\circ f)(x)=g(2x+3)=(2x+3)^2\). \((f\circ g)(x)=f(x^2)=2x^2+3\). These are different functions, so composition is not commutative.

2. \(g\circ f\) is not injective. Take \(x=-1\) and \(x=-2\). Then \((g\circ f)(-1)=1\) and \((g\circ f)(-2)=1\). Since \(-1\ne -2\) but the outputs agree, injectivity fails.

3. \(g\circ f\) is not surjective. Every value of \((2x+3)^2\) is nonnegative, so no negative target is attained. For instance, there is no \(x\in\mathbb R\) with \((g\circ f)(x)=-1\).

C4. Pigeonhole principle

Let \(A=\{1,2,3,4,5\}\) and \(B=\{a,b,c\}\).

  1. How many functions are there from \(A\) to \(B\)?
  2. Prove that no function from \(A\) to \(B\) is injective.
Show hint

For part 1, count independent choices of output for each of the five inputs. For part 2, compare the sizes of \(A\) and \(B\).

Show solution

1. Each of the five inputs has three independent choices of output, so there are \(3^5=243\) functions.

2. Suppose \(f:A\to B\) is injective. Then distinct elements of \(A\) must map to distinct elements of \(B\), so the image \(f(A)\) would have exactly \(|A|=5\) elements. But \(f(A)\subseteq B\) and \(|B|=3\), so \(|f(A)|\le 3\). This contradicts \(|f(A)|=5\). Hence no such \(f\) is injective.

C5. Counting bijections

Let \(A=\{1,2,3\}\) and \(B=\{a,b,c\}\).

  1. How many functions are there from \(A\) to \(B\)?
  2. How many of them are injective?
  3. How many are bijective?
  4. Generalize: how many bijections are there from a set of \(n\) elements to itself?
Show hint

For injective functions, count the available choices for the first input, then the second, then the third. For part 4, extend the same product to \(n\) inputs.

Show solution

1. \(3^3=27\).

2. The first input has 3 choices, the second has 2 remaining choices, and the third has 1 remaining choice. So there are \(3\cdot 2\cdot 1=6\) injective functions.

3. Every injective function from a finite set to a set of the same size is automatically surjective, hence bijective. So there are 6 bijections.

4. The same argument gives \(n!=n\cdot(n-1)\cdots 1\) bijections from an \(n\)-element set to itself. These are called permutations of the set.

Part II. Challenge problems

These problems require more careful quantifier manipulation and multi-step arguments.

H1. Inverse functions

Let \(f:\mathbb R\setminus\{1\}\to\mathbb R\setminus\{0\}\) be defined by

\[f(x)=\frac{1}{x-1}.\]
  1. Prove that \(f\) is injective.
  2. Prove that \(f\) is surjective.
  3. Find \(f^{-1}\).
Show hint

For surjectivity, start with an arbitrary \(y\ne 0\) and solve \(y=1/(x-1)\) for \(x\). Check that your answer lies in the domain \(\mathbb R\setminus\{1\}\).

Show solution

1. Suppose \(f(x_1)=f(x_2)\). Then \(1/(x_1-1)=1/(x_2-1)\). Cross-multiplying gives \(x_2-1=x_1-1\), so \(x_1=x_2\). Hence \(f\) is injective.

2. Let \(y\in\mathbb R\setminus\{0\}\). Solve \(y=1/(x-1)\): multiply both sides by \(x-1\) to get \(y(x-1)=1\), so \(x-1=1/y\) and \(x=1+1/y\). Since \(y\ne 0\), this expression is defined. Also \(1/y\ne 0\), so \(x\ne 1\), meaning \(x\) lies in the domain. Finally, \(f(x)=y\). Hence \(f\) is surjective.

3. From the surjectivity computation, \(f^{-1}(y)=1+1/y\).

H2. Composition and bijections

Let \(f:A\to B\) and \(g:B\to C\) be bijections.

  1. Prove that \(g\circ f:A\to C\) is a bijection.
  2. Prove that \((g\circ f)^{-1}=f^{-1}\circ g^{-1}\).
Show hint

For part 1, prove injectivity and surjectivity separately, using the corresponding property of \(f\) and \(g\) at each step. For part 2, show that the two functions agree on every element of \(C\).

Show solution

1. Injective: suppose \((g\circ f)(x_1)=(g\circ f)(x_2)\). Then \(g(f(x_1))=g(f(x_2))\). Since \(g\) is injective, \(f(x_1)=f(x_2)\). Since \(f\) is injective, \(x_1=x_2\). Surjective: let \(c\in C\). Since \(g\) is surjective, there is \(b\in B\) with \(g(b)=c\). Since \(f\) is surjective, there is \(a\in A\) with \(f(a)=b\). Then \((g\circ f)(a)=g(f(a))=g(b)=c\). Hence \(g\circ f\) is bijective.

2. Let \(c\in C\). Write \(b=g^{-1}(c)\in B\) and \(a=f^{-1}(b)\in A\). Then \((g\circ f)(a)=c\), so \((g\circ f)^{-1}(c)=a\). On the other hand, \((f^{-1}\circ g^{-1})(c)=f^{-1}(g^{-1}(c))=f^{-1}(b)=a\). Since the two functions agree on every \(c\in C\), they are equal.

H3. Infinite cardinality

Let \(S=\{n\in\mathbb Z:n\ge 0\}\) and \(T=\{n\in\mathbb Z:n\ge 1\}\). Define \(f:S\to T\) by \(f(n)=n+1\).

  1. Prove that \(f\) is a bijection.
  2. What does this imply about \(|S|\) and \(|T|\)?
  3. Is \(T\) a proper subset of \(S\)? Does this contradict your answer to part 2?
Show hint

For surjectivity, given \(y\in T\), you need an input in \(S\) whose successor is \(y\). For part 3, recall how cardinality is defined for infinite sets.

Show solution

1. Injective: if \(f(m)=f(n)\), then \(m+1=n+1\), so \(m=n\). Surjective: let \(y\in T\). Then \(y\ge 1\), so \(y-1\ge 0\), meaning \(y-1\in S\). Also \(f(y-1)=y\). Hence \(f\) is bijective.

2. Since there is a bijection between \(S\) and \(T\), the sets have the same cardinality: \(|S|=|T|\).

3. Yes, \(T\) is a proper subset of \(S\): the element \(0\) lies in \(S\) but not in \(T\). This does not contradict part 2, because for infinite sets a proper subset can have the same cardinality as the whole set.

H4. Proving a function is not injective

Let \(f:\mathbb R\to\mathbb R\), \(f(x)=x^4-x^2\).

  1. Prove that \(f\) is not injective.
  2. Find all \(x\) such that \(f(x)=0\).
  3. Is \(f\) surjective? Prove or disprove.
Show hint

For part 1, symmetric inputs often produce equal outputs. For part 3, look for a real number that no input maps to; a discriminant argument may help.

Show solution

1. Note that \(f(-1)=0\) and \(f(1)=0\). Since \(-1\ne 1\) but \(f(-1)=f(1)\), \(f\) is not injective.

2. Factor: \(x^4-x^2=x^2(x^2-1)=x^2(x-1)(x+1)\). So \(f(x)=0\) exactly when \(x=0\), \(x=1\), or \(x=-1\).

3. \(f\) is not surjective. Consider the target \(-1\). If \(f(x)=-1\), then \(x^4-x^2+1=0\). Let \(u=x^2\ge 0\). Then \(u^2-u+1=0\), whose discriminant is \(1-4=-3<0\), so there are no real solutions for \(u\), hence none for \(x\). Thus \(-1\) is not in the image of \(f\).

H5. Function definition and well-definedness

Let \(A=\{0,1,2,3\}\). Define a relation \(R\subseteq A\times A\) by

\[R=\{(0,0),(1,1),(2,2),(3,3),(0,1),(1,0)\}.\]
  1. Is \(R\) a function from \(A\) to \(A\)? Explain.
  2. If not, can you remove elements from \(R\) to make it a function? What is the smallest number of elements to remove?
  3. Can you remove elements to make it an injective function? A surjective function? A bijection?
Show hint

Recall the definition: a function must assign exactly one output to each input in the domain. Check each input \(0,1,2,3\) separately.

Show solution

1. \(R\) is not a function. Input \(0\) has two outputs, \(0\) and \(1\). Input \(1\) also has two outputs, \(1\) and \(0\). Uniqueness of outputs fails for these two inputs.

2. Inputs \(2\) and \(3\) already have exactly one output each. To repair input \(0\), remove either \((0,0)\) or \((0,1)\). To repair input \(1\), remove either \((1,1)\) or \((1,0)\). At least 2 elements must be removed. For example, removing \((0,1)\) and \((1,0)\) leaves \(R'=\{(0,0),(1,1),(2,2),(3,3)\}\), which is a function.

3. The repaired relation \(R'\) is injective, surjective, and therefore bijective. So removing 2 elements suffices to obtain a bijection.

Part III. Mixed review

Each problem below combines injectivity, surjectivity, and composition in a single argument. Write a complete proof before opening the solution.

M1. A function on the integers

Let \(f:\mathbb Z\to\mathbb Z\) be defined by \(f(n)=3n+1\), and let \(g:\mathbb Z\to\mathbb Z\) be defined by \(g(n)=n-1\).

  1. Prove that \(f\) is injective.
  2. Prove that \(f\) is not surjective.
  3. Compute \(g\circ f\) and \(f\circ g\). Are these the same function?
  4. Prove that \(g\circ f\) is injective but not surjective.
Show hint

For part 4, you may use the earlier results about composition: if \(g\circ f\) is injective then \(f\) is injective, and if \(g\circ f\) is surjective then \(g\) is surjective. But be careful — the converses do not hold. Here you need a direct argument for injectivity of \(g\circ f\), and a direct witness for its failure to be surjective.

Show solution

1. Suppose \(f(m)=f(n)\). Then \(3m+1=3n+1\), so \(3m=3n\), giving \(m=n\). Hence \(f\) is injective.

2. Consider the target \(0\in\mathbb Z\). If \(f(n)=0\), then \(3n+1=0\), so \(n=-1/3\notin\mathbb Z\). Hence \(0\) is not attained, and \(f\) is not surjective. More generally, the image of \(f\) is \(\{3n+1:n\in\mathbb Z\}\), the integers congruent to \(1\) modulo \(3\).

3. \((g\circ f)(n)=g(3n+1)=(3n+1)-1=3n\). \((f\circ g)(n)=f(n-1)=3(n-1)+1=3n-2\). These are different functions: for example, \((g\circ f)(0)=0\) while \((f\circ g)(0)=-2\).

4. Injective: suppose \((g\circ f)(m)=(g\circ f)(n)\). Then \(3m=3n\), so \(m=n\). Hence \(g\circ f\) is injective. Not surjective: the image of \(g\circ f\) is \(\{3n:n\in\mathbb Z\}\), the multiples of \(3\). The target \(1\in\mathbb Z\) is not a multiple of \(3\), so it is not attained. Hence \(g\circ f\) is not surjective.

M2. A function on the reals

Let \(f:\mathbb R\to\mathbb R\) be defined by \(f(x)=2x+5\), and let \(g:\mathbb R\to\mathbb R\) be defined by \(g(x)=(x-5)/2\).

  1. Prove that \(f\) is a bijection.
  2. Find \(f^{-1}\).
  3. Prove that \(g=f^{-1}\).
  4. Compute \(g\circ f\) and \(f\circ g\), and explain why the results are identity functions.
  5. Now let \(h:\mathbb R\to\mathbb R\) be defined by \(h(x)=x^3\). Prove that \(h\circ f\) is a bijection.
Show hint

For part 5, use the fact that a composition of bijections is a bijection, and prove separately that \(h\) is a bijection. Alternatively, prove the result directly by showing \(h\circ f\) is injective and surjective.

Show solution

1. Injective: if \(f(x_1)=f(x_2)\), then \(2x_1+5=2x_2+5\), so \(x_1=x_2\). Surjective: let \(y\in\mathbb R\). Choose \(x=(y-5)/2\in\mathbb R\). Then \(f(x)=2\cdot(y-5)/2+5=y\). Hence \(f\) is a bijection.

2. From the surjectivity argument, \(f^{-1}(y)=(y-5)/2\).

3. The formula for \(g\) matches \(f^{-1}\) exactly: \(g(y)=(y-5)/2=f^{-1}(y)\). Hence \(g=f^{-1}\).

4. \((g\circ f)(x)=g(2x+5)=((2x+5)-5)/2=x\). \((f\circ g)(x)=f((x-5)/2)=2\cdot(x-5)/2+5=x\). Both compositions return the input unchanged, so they are the identity functions on \(\mathbb R\). This is exactly the defining property of inverse functions.

5. First, \(h\) is a bijection. Injective: if \(m^3=n^3\), then \(m=n\), since the cube function is strictly increasing on \(\mathbb R\). Surjective: given \(y\in\mathbb R\), choose \(x=\sqrt[3]{y}\in\mathbb R\); then \(h(x)=y\). Since \(f\) and \(h\) are bijections, their composition \(h\circ f\) is a bijection by the composition theorem. Concretely, \((h\circ f)(x)=(2x+5)^3\), which is injective and surjective on \(\mathbb R\).

M3. A composition with a twist

Let \(f:\mathbb R\to\mathbb R\) be defined by \(f(x)=x^2\), and let \(g:\mathbb R\to\mathbb R\) be defined by \(g(x)=x+1\).

  1. Prove that \(f\) is neither injective nor surjective.
  2. Prove that \(g\) is a bijection.
  3. Compute \(g\circ f\) and \(f\circ g\). Are they injective? Surjective? Justify your answers.
  4. Explain why the fact that \(g\) is a bijection does not make \(g\circ f\) a bijection.
Show hint

For part 3, plug in values and look for repeated outputs and missing outputs. For part 4, recall the composition theorem: the composition of two bijections is a bijection, but here only one of the two functions is a bijection.

Show solution

1. Not injective: \(f(-1)=1=f(1)\), but \(-1\ne 1\). Not surjective: every square is nonnegative, so no negative real number is attained. For instance, \(-1\) is not in the image of \(f\).

2. Injective: if \(g(x_1)=g(x_2)\), then \(x_1+1=x_2+1\), so \(x_1=x_2\). Surjective: given \(y\in\mathbb R\), choose \(x=y-1\in\mathbb R\); then \(g(x)=y\). Hence \(g\) is a bijection.

3. \((g\circ f)(x)=g(x^2)=x^2+1\). \((f\circ g)(x)=f(x+1)=(x+1)^2\). \(g\circ f\): not injective, since \((g\circ f)(-1)=2=(g\circ f)(1)\); not surjective, since \(x^2+1\ge 1\), so \(0\) is not attained. \(f\circ g\): not injective, since \((f\circ g)(-2)=1=(f\circ g)(0)\); not surjective, since \((x+1)^2\ge 0\), so \(-1\) is not attained.

4. The theorem states that the composition of two bijections is a bijection. Here \(f\) is not a bijection, so the theorem does not apply. The outer function \(g\) being bijective is not enough to rescue injectivity or surjectivity of the composition, because the inner function \(f\) already collapses distinct inputs together (breaking injectivity) and misses negative outputs (breaking surjectivity). The composition inherits both failures.
