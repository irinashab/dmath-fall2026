1. From a predicate to a set

Opening question

Consider \[A=\{x\in\mathbb Z:x^2<9\}.\]

  1. List all elements of \(A\).
  2. What does the statement \(x\in A\) tell you?
  3. What changes if we replace \(\mathbb Z\) with \(\mathbb R\)?
Show solution

\(A=\{-2,-1,0,1,2\}\). Membership means that \(x\) is an integer and \(x^2<9\). Over the real numbers, every real number strictly between \(-3\) and \(3\) belongs to the set, so we get the interval \((-3,3)\).

A set is an unordered collection of distinct objects, called its elements. We write \(x\in A\) when \(x\) is an element of \(A\), and \(x\notin A\) when it is not.

We can describe a set by listing its elements or by giving a condition that selects elements from a specified domain:

\[\{x\in U:P(x)\}.\]

Read this as “the set of all \(x\) in \(U\) such that \(P(x)\).” For \(x\in U\), membership in this set is equivalent to \(P(x)\).

  • Order does not matter: \(\{1,2,3\}=\{3,1,2\}\).
  • Repetition does not matter: \(\{1,1,2\}=\{1,2\}\).
  • Elements can themselves be sets. We will return to this idea when we discuss power sets.

Some familiar sets

  • \(\mathbb N=\{0,1,2,\ldots\}\): the natural numbers. In this course, zero is included.
  • \(\mathbb Z=\{\ldots,-2,-1,0,1,2,\ldots\}\): the integers.
  • \(\mathbb Q=\{m/n:m,n\in\mathbb Z,\ n\ne0\}\): the rational numbers.
  • \(\mathbb R\): the real numbers.
  • \(\emptyset\): the set with no elements.

A short historical note

Modern set theory grew out of nineteenth-century work on real numbers and infinite collections. Georg Cantor’s 1874 paper showed that the real numbers cannot all be placed in a sequence indexed by the natural numbers. It opened the way to distinguishing different sizes of infinity.

Today we begin with the language of sets. In the next lecture, functions and one-to-one correspondences will give us a way to compare their sizes.

Historical source: MacTutor History of Mathematics, The beginnings of set theory.

Optional historical afterthought: Russell’s paradox

In 1901, Bertrand Russell found a contradiction in the idea that every condition defines a set. Suppose there were a set

\[R=\{X:X\text{ is a set and }X\notin X\}.\]

In words, it would contain exactly those sets that are not elements of themselves. Now ask: is \(R\in R\)?

  • If \(R\in R\), it must satisfy the defining condition, so \(R\notin R\).
  • If \(R\notin R\), it satisfies the defining condition, so \(R\in R\).

Either answer leads to a contradiction. The conclusion is that no set with this unrestricted description exists.

We will not develop set-theory axioms here. Our set-builder notation \(\{x\in U:P(x)\}\) selects elements from an already specified set \(U\); it does not assume that every unrestricted description produces a set.

Source: Stanford Encyclopedia of Philosophy, Russell’s Paradox.

2. Set operations and logical connectives

Set operations let us build new sets from existing ones. Their definitions use the logical connectives we already know. In the formulas below, \(x\) ranges over an ambient set containing \(A\) and \(B\).

Union

\[x\in A\cup B\iff(x\in A\lor x\in B).\]

The union contains elements in either set, including elements in both. The word “or” is inclusive.

Intersection

\[x\in A\cap B\iff(x\in A\land x\in B).\]

The intersection contains precisely the elements common to both sets.

Set difference

\[x\in A\setminus B\iff(x\in A\land x\notin B).\]

The difference keeps the elements of \(A\) that do not belong to \(B\). The order matters.

The rectangle gives a surrounding universe for each picture. Shading identifies the selected region; it does not tell us how many elements the sets contain.

Compute, then explain

Let \(A=\{1,2,3,4,5\}\) and \(B=\{2,4,6,8,10\}\). Find \(A\cap B\), \(A\cup B\), \(A\setminus B\), and \(B\setminus A\).

If \(x\in A\setminus B\), what two facts do you know? If \(x\in A\cup B\), can you conclude that \(x\in A\)?

Show solution
  • \(A\cap B=\{2,4\}\).
  • \(A\cup B=\{1,2,3,4,5,6,8,10\}\).
  • \(A\setminus B=\{1,3,5\}\).
  • \(B\setminus A=\{6,8,10\}\).

Membership in the difference tells us both \(x\in A\) and \(x\notin B\). Membership in the union does not guarantee membership in \(A\): for example, \(6\in A\cup B\), but \(6\notin A\).

3. Subsets and proof setups

We say \(A\) is a subset of \(B\), written \(A\subseteq B\), when every element of \(A\) is also an element of \(B\).

\[A\subseteq B\iff\forall x\,(x\in A\rightarrow x\in B).\]

Equality is allowed: every set is a subset of itself. For example, \(\mathbb N\subseteq\mathbb Z\) and \(\{1,2\}\subseteq\{1,2,3\}\).

Negate the definition

Complete the statement: “\(A\) is not a subset of \(B\) if and only if there exists…”

Show solution\[A\nsubseteq B\iff\exists x\,(x\in A\land x\notin B).\]

A counterexample must belong to \(A\) and fail to belong to \(B\). Merely finding an element outside \(B\) is not enough.

Build a proof together

Prove \(B\subseteq A\cup B\).

  1. Take an arbitrary element of which set?
  2. What must you show about that element?
  3. Which definition lets you finish?
Show the completed proof

Let \(x\in B\) be arbitrary. Then \(x\in A\) or \(x\in B\), since the second statement is true. By the definition of union, \(x\in A\cup B\). Therefore \(B\subseteq A\cup B\).

Your turn

Prove \(A\cap B\subseteq A\). Begin by stating your assumption about an arbitrary element.

Show solution

Let \(x\in A\cap B\). By definition, \(x\in A\) and \(x\in B\); in particular, \(x\in A\). Therefore \(A\cap B\subseteq A\).

Proof or counterexample?

Let \(A=\{x\in\mathbb Z:x^2<9\}\) and \(B=\{x\in\mathbb Z:x<3\}\).

  1. Is \(A\subseteq B\)?
  2. Is \(B\subseteq A\)?

Justify each answer.

Show solution

Yes, \(A\subseteq B\): the elements of \(A\) are \(-2,-1,0,1,2\), and each is less than 3.

No, \(B\nsubseteq A\): \(-3\in B\), but \((-3)^2=9\), so \(-3\notin A\).

4. The empty set

The empty set contains no elements. Is it a subset of \(\{1,2,3\}\)? More generally, is it a subset of every set?

What would failure require?

If \(\emptyset\subseteq A\) were false, what would have to exist? Write the negation before explaining your answer.

Show solution

Failure would require \[\exists x\,(x\in\emptyset\land x\notin A).\]There is no element of \(\emptyset\), so this is impossible. Therefore \(\emptyset\subseteq A\) for every set \(A\).

Equivalently, the implication \(x\in\emptyset\rightarrow x\in A\) is true for every \(x\): its antecedent is always false. This is an application of vacuous truth.

Element or subset?

Explain why \(\emptyset\subseteq\{1,2\}\) is true, but \(\emptyset\in\{1,2\}\) is false.

Show solution

The empty set is a subset of every set. But the only elements of \(\{1,2\}\) are 1 and 2; the empty set is neither of those elements.

5. Equality of sets

Two sets are equal if and only if they have exactly the same elements. Different descriptions may define the same set.

\[A=B\iff\forall x\,(x\in A\leftrightarrow x\in B).\]

This gives a useful proof method:

\[A=B\iff(A\subseteq B\land B\subseteq A).\]

Prove that every element of the first set is in the second, and then prove the reverse inclusion.

A different description of the same integers

\[A=\{2n:n\in\mathbb Z\},\qquad B=\{2m+2:m\in\mathbb Z\}.\]

Both sets describe the even integers. Let us justify that observation by constructing witnesses.

First inclusion, with a missing step

Let \(x\in A\). There is an integer \(n\) such that \(x=2n\). To prove \(x\in B\), we need an integer \(m\) for which \(x=2m+2\).

What should \(m\) be? Why is your choice an integer?

Show solution

Choose \(m=n-1\). Since \(n\in\mathbb Z\), also \(m\in\mathbb Z\). Then \[2m+2=2(n-1)+2=2n=x.\]Thus \(x\in B\), proving \(A\subseteq B\).

Reverse inclusion, on your own

Prove \(B\subseteq A\). State the integer witness you choose and check that it works.

Show solution

Let \(x\in B\). Then \(x=2m+2\) for some \(m\in\mathbb Z\). Choose \(n=m+1\in\mathbb Z\). Since \(x=2(m+1)=2n\), we have \(x\in A\). Thus \(B\subseteq A\).

Both inclusions hold, so \(A=B\).

The witnesses \(m\) and \(n\) do not have to be the same integer. What matters is that each element has the required representation in the other set.

6. Power sets

The power set of \(A\) is the set of all subsets of \(A\):

\[\mathcal P(A)=\{X:X\subseteq A\}.\]

This definition connects two kinds of statements:

\[X\in\mathcal P(A)\iff X\subseteq A.\]

An element of a power set is itself a set.

List the subsets

Find \(\mathcal P(\{1,2\})\). Include the empty set and the original set.

Show solution\[\mathcal P(\{1,2\})=\{\emptyset,\{1\},\{2\},\{1,2\}\}.\]

There are four elements, and each of them is a subset of \(\{1,2\}\).

Read each symbol carefully

For \(A=\{1,2\}\), decide whether each statement is true or false and explain why.

  1. \(1\in A\)
  2. \(\{1\}\subseteq A\)
  3. \(\{1\}\in\mathcal P(A)\)
  4. \(\emptyset\in A\)
  5. \(\emptyset\in\mathcal P(A)\)
Show solution

The answers are true, true, true, false, true. In particular, \(\emptyset\) is not an element of \(A\), but it is a subset of \(A\), so it is an element of \(\mathcal P(A)\).

The smallest power set

What is \(\mathcal P(\emptyset)\)? How many elements does it have?

Show solution

The only subset of \(\emptyset\) is \(\emptyset\) itself. Thus \[\mathcal P(\emptyset)=\{\emptyset\}.\]This power set has one element. The sets \(\emptyset\) and \(\{\emptyset\}\) are different.

Looking ahead: How can we systematically list every subset of a larger finite set? Next time, we will connect this question to binary strings and counting.

7. Afterthought proofs

Use the final proof workshop to put today’s definitions together. Begin independently, then compare with a partner. Each person should write an argument. Try both core problems before opening the solutions; the extension is for early finishers.

1. Subsets in a chain

Suppose \(A\subseteq B\) and \(B\subseteq C\). Prove \(A\subseteq C\).

Show hint

Start with an arbitrary \(x\in A\). Apply each assumption in turn.

Show solution

Let \(x\in A\). Since \(A\subseteq B\), we have \(x\in B\). Since \(B\subseteq C\), we have \(x\in C\). Therefore \(A\subseteq C\).

2. When does an intersection equal one of its sets?

Prove both directions:

\[A\cap B=A\iff A\subseteq B.\]
Show hint

For the forward direction, assume the equality and start with an element of \(A\). For the reverse direction, assume the inclusion and prove the two inclusions needed for equality.

Show solution

Forward: Assume \(A\cap B=A\). Let \(x\in A\). Then \(x\in A\cap B\), so \(x\in B\). Therefore \(A\subseteq B\).

Reverse: Assume \(A\subseteq B\). If \(x\in A\cap B\), then \(x\in A\); hence \(A\cap B\subseteq A\). Conversely, if \(x\in A\), our assumption gives \(x\in B\), so \(x\in A\cap B\). Hence \(A\subseteq A\cap B\). The two inclusions prove \(A\cap B=A\).

Extension. Power sets preserve inclusion

Suppose \(A\subseteq B\). Prove \(\mathcal P(A)\subseteq\mathcal P(B)\).

Show hint

Start with \(X\in\mathcal P(A)\). Translate that membership statement, then use the chain result from Problem 1.

Show solution

Let \(X\in\mathcal P(A)\). Then \(X\subseteq A\). Since \(A\subseteq B\), Problem 1 gives \(X\subseteq B\). Thus \(X\in\mathcal P(B)\). Therefore \(\mathcal P(A)\subseteq\mathcal P(B)\).

Before you leave

  1. Prove \(A\setminus B\subseteq A\).
  2. Explain the difference between \(\emptyset\) and \(\{\emptyset\}\).
Review after writing your answers

Let \(x\in A\setminus B\). Then \(x\in A\) and \(x\notin B\); in particular, \(x\in A\). Therefore \(A\setminus B\subseteq A\).

The empty set has no elements. The set \(\{\emptyset\}\) has one element, namely the empty set.
