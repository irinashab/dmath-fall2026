Lesson 18: Graph Structure, Symmetry, Connectivity, Trees

1. Warm-up: how many isomorphisms?

MAT 3120 · Discrete Mathematics · Fall 2026

Last lecture, we learned to recognize when two graphs have the same adjacency structure. Today we begin with a more precise question: once an isomorphism exists, how many choices can there be?

Conventions. Throughout this lecture, graphs are finite, simple, and undirected. Trees are nonempty. As in Lecture 16, a path is a walk with no repeated vertices; its length is its number of edges. A cycle is a nonempty closed trail with no repeated vertices except the first and last. Under our simple-graph convention, every cycle has at least three edges. Edge crossings without a marked vertex do not create vertices.

2. Automorphisms: symmetry of adjacency

What happens when the source and target are the same graph? An automorphism of G is an isomorphism \(\alpha:V(G)\to V(G)\). Thus \(\alpha\) is a bijection satisfying

\[\{u,v\}\in E(G)\quad\Longleftrightarrow\quad\{\alpha(u),\alpha(v)\}\in E(G).\]

The set of all automorphisms is denoted \(\operatorname{Aut}(G)\). The identity map fixes every vertex and is always an automorphism. A nontrivial automorphism moves at least one vertex. Here labels name the vertices so we can describe a permutation; they are not extra constraints requiring vertices to stay fixed.

Examples: stars and complete graphs

In the star \(K_{1,3}\), the unique vertex of degree 3 must remain fixed. Its three leaves may be permuted arbitrarily: each is adjacent only to the center. Every permutation of the leaves is allowed, so there are \(3!=6\) automorphisms.

Draw the star with equal-length arms separated by 120°. Its six automorphisms can then all be realized geometrically: the identity, two nonidentity rotations, and three reflections. In the panels below, the identity panel gives the starting positions; the other panels show where each original vertex label moves. The center \(o\) is fixed in every panel. Dashed lines mark reflection axes.

In \(K_n\), every pair of distinct vertices is adjacent. Every vertex permutation therefore preserves adjacency, and \(|\operatorname{Aut}(K_n)|=n!\), for \(n\ge1\). In our warm-up graph, the same pair argument gives \(|\operatorname{Aut}(K_{2,2,2})|=48\).

Geometric symmetry versus graph symmetry

A rotation or reflection that carries a drawing, including its edges, onto itself induces an automorphism. But an automorphism need not be realized by a rigid motion of a particular drawing. Draw the three leaves of \(K_{1,3}\) at three different distances from its center: all six graph automorphisms remain, even though the drawing can have no nonidentity Euclidean symmetry. Edge lengths, angles, and crossing positions are not part of an ordinary graph's adjacency structure.

Rigid graphs

A graph is rigid (or asymmetric) if its only automorphism is the identity. A drawing that looks irregular does not by itself establish rigidity; we must show that every adjacency-preserving permutation fixes every vertex.

In this example, r is the unique degree-3 vertex, so it is fixed. Removing r leaves three connected pieces with 1, 2, and 3 vertices. Any automorphism fixing r must preserve each of these pieces, since their sizes differ. Within each arm, the vertices occur at distinct distances from r, and these distances are preserved by automorphisms. Thus every vertex is fixed, proving that the graph is rigid. We will formalize connected pieces and distance below.

Why automorphisms count isomorphisms

Proposition. If \(G\cong H\), then \(|\operatorname{Iso}(G,H)|=|\operatorname{Aut}(G)|\).

Proof. Fix one isomorphism \(f:G\to H\). Define

\[\Phi:\operatorname{Aut}(G)\longrightarrow\operatorname{Iso}(G,H),\qquad\Phi(\alpha)=f\circ\alpha.\]

A composition of isomorphisms is an isomorphism, so this map is well defined. Its inverse sends \(g:G\to H\) to \(f^{-1}\circ g\), an automorphism of G. Indeed,

\[f^{-1}\circ(f\circ\alpha)=\alpha,\qquad f\circ(f^{-1}\circ g)=g.\]

These constructions are inverse bijections, proving the claim. Applying the same argument with G and H exchanged also gives \(|\operatorname{Aut}(G)|=|\operatorname{Aut}(H)|\). ∎

Check. If G is rigid and \(G\cong H\), how many isomorphisms G → H are there? Exactly one. If the graphs are not isomorphic, there are zero; the proposition assumes an initial isomorphism exists.

3. Connectivity and components

Recall the terminology from Lecture 16:

  • A walk is an alternating sequence \(v_0,e_1,v_1,\ldots,e_k,v_k\), where each edge \(e_i\) joins \(v_{i-1}\) and \(v_i\). Vertices and edges may repeat. Specifying edges is essential when parallel edges exist; in this lecture's simple graphs, consecutive vertices determine the edge uniquely.
  • A trail is a walk with no repeated edges.
  • A path is a walk with no repeated vertices.
  • A walk is closed if its starting and ending vertices coincide. A cycle is a nonempty closed trail with no repeated vertices except the first and last.

For example, in the warm-up graph G, a–b–e–a–b is a walk but not a trail, because it repeats edge ab. The sequence a–b–e–a is a cycle and a trail, but not a path, because it repeats a. The sequence a–b–e is a path.

Whenever a walk repeats a vertex, delete the portion between two occurrences. Repeating this deletion produces a path with the same endpoints (possibly the length-zero path). Thus a walk between two vertices exists if and only if a path does.

A nonempty graph is connected if every pair of distinct vertices is joined by a path. A single vertex is connected: the condition has no distinct pair to check. We also allow the length-zero path from a vertex to itself.

Define \(u\sim v\) when a path joins u to v. This relation is reflexive (the length-zero path), symmetric (reverse a path), and transitive (concatenate paths to obtain a walk, then remove repetitions). It is therefore an equivalence relation.

A connected component is the subgraph induced by one equivalence class. Equivalently, it is a maximal connected subgraph: it cannot be enlarged within G while remaining connected. Components partition the vertex set, and no edge joins two different components.

Here the component vertex sets are \(\{a,b,c\}\), \(\{d,e\}\), and \(\{f\}\). The isolated vertex f is a whole component, even though it has no incident edges.

For vertices in the same component, their distance \(d(u,v)\) is the length of a shortest path joining them. In different components there is no such finite distance. Isomorphisms carry paths to paths, and their inverses do the same; consequently they preserve distances and map whole components to whole components.

Why can adding an edge between two components reduce the number of components by exactly one? Why can adding an edge within a component leave the number unchanged?

4. Trees, forests, and unique paths

A tree is a nonempty connected graph with no cycles. A forest is a graph with no cycles; each of its connected components is a tree. A single vertex is a tree. A forest may have isolated vertices and need not be connected. We also allow the empty graph as a forest (with no components).

Unique-path theorem. A nonempty graph is a tree if and only if exactly one path joins every pair of distinct vertices.

Proof, forward direction. Let T be a tree. Connectivity gives a path between any two distinct vertices u and v. Suppose P and Q were two different u–v paths. Follow them from u through their common initial segment to the vertex x where they first diverge. Follow P beyond x until its first vertex y that also lies on the part of Q after x; such a vertex exists because v is on both paths. By the choice of y, the two x–y segments of P and Q are internally disjoint: their only common vertices are x and y. They also have different first edges. Together they form a cycle, contradicting acyclicity. The path is therefore unique.

Reverse direction. Suppose exactly one path joins every pair of distinct vertices. The graph is connected. If it contained a cycle, choose an edge uv of that cycle. The edge itself and the rest of the cycle would be two different u–v paths, a contradiction. Thus the graph is acyclic and hence a tree. ∎

Two useful consequences.

  • Removing any edge uv of a tree disconnects it: otherwise the remaining graph would contain another u–v path, contradicting uniqueness. Such an edge is called a bridge.
  • Adding one new edge uv between nonadjacent vertices of a tree creates exactly one cycle: the new edge together with the unique old u–v path. Every new cycle must use the new edge, and deleting that edge from a cycle must leave that unique path.

The leaf lemma

A tree with no distinguished vertex is called an unrooted tree. A rooted tree is a tree together with a chosen vertex called its root. So far our tree statements concern unrooted trees: no root is needed. We will develop rooted-tree terminology in Section 5.

A leaf of an unrooted tree is a vertex of degree 1. The single vertex of a one-vertex tree has degree 0, so it is not a leaf under this convention.

Lemma. Every finite tree with at least two vertices has at least two leaves.

Proof. Choose a path of maximum length, possible because the tree is finite. Its endpoints are distinct. Let x be one endpoint, and let y be its neighbor along the path. If x had another neighbor z outside the path, we could extend the path, contradicting maximal length. If z were elsewhere on the path, the edge xz and the intervening path segment would form a cycle. Both possibilities are impossible. Thus x has only neighbor y and is a leaf. The same argument applies to the other endpoint. ∎

Why leaf removal preserves a tree. Delete a leaf x and its one incident edge from a tree with at least two vertices. No new cycle can appear. A path between any two remaining vertices cannot use x internally, because an internal vertex of a path has two distinct incident path edges. Hence the remaining vertices are still connected. The smaller graph is a tree.

A tree on n vertices has n − 1 edges

Theorem. If T is a finite tree with \(n\ge1\) vertices, then \(|E(T)|=n-1\).

Proof by induction on n. For \(n=1\), simplicity gives no edges, so \(|E(T)|=0=n-1\). For the inductive step, let \(n\ge2\) and assume every tree with \(n-1\) vertices has \(n-2\) edges. By the leaf lemma, T has a leaf. Remove it and its incident edge. The remaining graph is a tree on \(n-1\) vertices, so it has \(n-2\) edges by the induction hypothesis. Restoring the one removed edge gives \((n-2)+1=n-1\) edges. ∎

Forest formula. If a forest has n vertices and k components, with component sizes \(n_1,\ldots,n_k\), then

\[|E|=\sum_{i=1}^k(n_i-1)=n-k.\]

For the empty forest, n = k = 0 and the same formula holds. An edge count alone does not establish that a graph is a tree: a triangle together with an isolated vertex has four vertices and three edges, but it is disconnected and contains a cycle.

5. Choosing a root

Recall that a rooted tree is a tree with one distinguished vertex \(r\), called its root. Choosing a root adds a reference point; it does not change the underlying edges. Unique paths make the following terminology well defined.

  • The parent of a vertex other than \(r\) is its neighbor immediately preceding it on the path from \(r\). The root has no parent.
  • The children of a vertex are the vertices for which it is the parent. Vertices with the same parent are siblings.
  • The ancestors of \(v\) are the other vertices on the root-to-\(v\) path. A vertex \(w\) is a descendant of \(v\) when \(v\) is an ancestor of \(w\).
  • The depth of \(v\) is \(d(r,v)\), counted in edges. The height of the rooted tree is the largest depth.
  • A rooted leaf has no children; an internal vertex has at least one child. The subtree rooted at \(v\) consists of \(v\) and all its descendants, with the edges between them.

In the diagram, \(d\) has parent \(a\) and child \(f\). Vertices \(c\) and \(d\) are siblings. The depth of \(f\) is 3, and the height is 3. The ancestors of \(f\) are \(r\), \(a\), and \(d\). The subtree rooted at \(a\) has vertices \(\{a,c,d,f\}\). The rooted leaves are \(c\), \(e\), and \(f\).

How the leaf definitions fit together. In an unrooted tree, a leaf has degree 1. In a rooted tree, a leaf has no children. For any vertex other than the root, these conditions are equivalent: it has exactly one parent, so its degree is 1 plus its number of children. The root is the exception because it has no parent. A root of degree 1 has one child, so it is not a rooted leaf, even though it is a leaf of the underlying unrooted tree. In the one-vertex rooted tree, the root has no children and is a rooted leaf, although its degree is 0.

6. Spanning trees: remove cycles, retain connection

A spanning tree of G is a subgraph T with \(V(T)=V(G)\), \(E(T)\subseteq E(G)\), and T a tree. “Spanning” requires every original vertex, not every original edge.

Theorem. Every finite nonempty connected graph has a spanning tree.

Constructive proof. Begin with G. If the current graph contains a cycle, choose an edge uv on that cycle and delete that edge, retaining all vertices. The remaining portion of the cycle still joins u to v. To see that the whole graph stays connected, take a path between any two vertices before the deletion. If it uses uv, replace that edge by the other u–v route around the cycle. This produces a walk avoiding the deleted edge; removing repeated portions gives a path. If the path did not use uv, it survives unchanged.

Repeat whenever a cycle remains. Each step removes one edge, so finiteness guarantees termination. Connectivity and the vertex set are preserved at every step. At termination, the remaining graph is connected, contains every original vertex, and has no cycles. It is therefore a spanning tree. ∎

In this example, first remove ac from triangle a–b–c–a. The four-cycle a–b–c–d–a remains, so next remove da. The three retained edges form a spanning tree. A different sequence can give a different spanning tree; for example, the edges ab, ac, ad form another one.

The key distinction. An edge on a cycle can be removed while preserving connectivity. Every edge of a tree is a bridge, so removing it disconnects the tree. The construction stops exactly when there are no cycle edges left to remove.

Consequences. A connected graph on n vertices has at least \(n-1\) edges because it contains a spanning tree. If it has exactly \(n-1\) edges, its spanning tree already uses all its edges, so the graph itself is a tree. Thus, for a nonempty graph on n vertices, each of the following characterizes a tree:

  • It is connected and acyclic.
  • Every pair of distinct vertices is joined by exactly one path.
  • It is connected and has \(n-1\) edges.
  • It is acyclic and has \(n-1\) edges: the forest formula forces one component.

If the original graph has k components, perform the same cycle-removal procedure in each component to obtain a spanning forest with \(n-k\) edges.
