How to Find My Comments on Your Problem Sets

Some of you have reported difficulties finding my comments on your problem set submissions. The comments are in the Feedback pull request,
not in the main repository files.
To find them:

  1. Open your problem set repository on GitHub.
  2. Click the Pull requests tab.
  3. Open Feedback #1.
  4. Check the Conversation tab for general comments and the Files changed tab for comments on specific parts of your solutions.
If you don't see Feedback #1, click Closed under Pull requests and look for it there. I will double-check that all feedback pull requests are open. If you still cannot find my comments, please let me know. You can also reply to my comments directly in the pull request, particularly when submitting corrections.
