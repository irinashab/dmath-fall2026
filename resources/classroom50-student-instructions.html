Using Classroom50

Student instructions for Discrete Mathematics

The short version: accept the assignment, open the private repository created for you, upload the required file to the main branch, and verify that the file opens.

What you need

  • A GitHub account connected to your Purchase College email address.
  • Membership in the course GitHub organization, dmath-fall2026.
  • The assignment link posted on the course page.

You do not need to create a personal access token. Tokens are part of the instructor's setup, not the student submission process.

0. Create your GitHub account

Complete this step before trying to join the course organization.

  1. Go to github.com/signup.
  2. Create an account using your Purchase College email address.
  3. Choose a username you will be comfortable using for coursework. Your username will appear in the name of every assignment repository.
  4. Open the verification message GitHub sends to your Purchase email and verify the address.
  5. Make a note of your GitHub username; your instructor may ask for it if there is a problem with your enrollment.
Already have a GitHub account? Do not create a second one. In GitHub, open Settings → Emails, add your Purchase College email address, and verify it. Continue using your existing account for the course.

1. Join the course organization

This is a one-time step.

  1. Look for the GitHub organization invitation sent by your instructor.
  2. Sign in to the GitHub account you will use for the course.
  3. Accept the invitation to join dmath-fall2026.
  4. Go to classroom50.org and choose Sign in with GitHub.
  5. Find dmath-fall2026, marked Student, and open it.
Use the same GitHub account throughout the course. If you accept the organization invitation with one account and open the assignment with another, Classroom50 may not recognize you correctly.

2. Accept an assignment

  1. Open the assignment link posted on the course page.
  2. Sign in to Classroom50 with GitHub if asked.
  3. Click Accept assignment.
  4. Wait while Classroom50 creates your private assignment repository.
  5. Open the repository when the confirmation page appears.

Everyone receives the same assignment link, but Classroom50 creates a different private repository for each student. Its name ends with your GitHub username.

You accept each assignment only once. Reopening its link will not create a second repository.

3. Find your repository later

The best route is through Classroom50:

  1. Sign in at classroom50.org.
  2. Open the dmath-fall2026 organization marked Student.
  3. Select the assignment you previously accepted.
  4. Open your assignment repository.

You can also find it on GitHub under Your repositories, but you should not need to hunt for it there.

4. Prepare the required file

Follow the naming and file-format directions in the assignment's README.md. For a PDF submission:

  1. Compile or export your work as a genuine PDF.
  2. Open the PDF on your own computer before uploading it.
  3. Confirm that the document displays correctly and contains your completed work.
  4. Give it the exact filename requested in the assignment.
Changing a filename does not change its file type. Renaming work.tex to work.pdf does not create a PDF. You must compile the LaTeX source and upload the resulting PDF file.

5. Upload your work

  1. Open your personal assignment repository.
  2. Check the branch selector near the upper-left corner. It must say main.
  3. Click Add file, then Upload files.
  4. Drag the required file onto the page, or click choose your files.
  5. Wait until the filename appears in the upload list.
  6. In the commit-message box, briefly describe what you are submitting, for example Submit Practice 0.
  7. Choose Commit directly to the main branch.
  8. Click Commit changes.

The commit is the upload. For these manually graded assignments, there is no additional Submit button, tag, release, or token.

6. Verify the submission

Do not stop immediately after clicking Commit changes.

  • The branch selector says main.
  • The required filename appears in the repository's file list.
  • Clicking the filename opens a valid preview or downloads a file that opens correctly.
  • The document contains the work you intended to submit.

If GitHub says Invalid PDF or shows LaTeX code instead of a document, you did not upload a valid PDF.

7. Correct or replace a file

You may upload a corrected file to the same repository before the deadline:

  1. Fix the original document and produce a new, valid output file.
  2. Open the new file on your computer and check it.
  3. Give it exactly the same required filename.
  4. Return to the repository's main branch.
  5. Use Add file → Upload files and upload the corrected file.
  6. Commit the replacement directly to main.
  7. Open the file from the repository once more to verify it.

GitHub keeps the earlier versions in the commit history, while the repository's main page shows the newest version.

8. Submission status and grades

These assignments are graded manually. Classroom50 may continue to display Accepted · awaiting submission even after you have uploaded your work. This does not mean that your file disappeared.

Your instructor will check the file in your private repository and enter the score manually. You can view your own information by opening the assignment and choosing My submission.

If something goes wrong

You cannot see the course organization

Confirm that you accepted the GitHub organization invitation and that you are signed in with the same GitHub account.

You cannot find your assignment repository

Return to Classroom50, open dmath-fall2026, and select the assignment. You may also reopen the assignment link from the course page.

You cannot upload a file

Confirm that you are in your personal assignment repository—not the template repository—and that the branch is main. If the assignment has been closed, contact the instructor.

The PDF will not open

Open the source in your LaTeX editor, compile it, download the resulting PDF, and test that PDF locally. Then upload the valid PDF again using the required filename.

You uploaded the wrong file

Upload the correct file using the same filename and commit it to main. Then verify the replacement from the repository page.
