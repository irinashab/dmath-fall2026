LaTeX Instructions

“TeX is intended for the creation of beautiful books—and especially for books that contain a lot of mathematics.”

—Donald E. Knuth, The TeXbook

Have you ever wondered how mathematical articles are typed? We do not have symbols on the keyboard for things like exponents, so \(x^2\) might not be so easy to write. \(\pi\) will certainly not appear on your keyboard, either, and good luck finding the symbol for \(\int\).

The answer is called LaTeX. LaTeX is a document preparation and typesetting system. In mathematics, it is the standard for writing articles, books, and problem sets. Although Microsoft Word and Google Docs can handle mathematical equations, using them for documents with a lot of mathematics can be cumbersome. These course notes are a minor exception: I am using GitHub Pages to write HTML and MathJax (a JavaScript library that renders LaTeX notation on the web).

Setting up

There are several ways to set up and install LaTeX. If you prefer not to install anything on your computer, you can create a free account on Overleaf. This is the simplest way to get up and running.

If you prefer to use LaTeX on your own computer, you will need two things:

  1. A LaTeX distribution: either MacTeX for macOS or MiKTeX for Windows.
  2. A LaTeX editor: my preference is TeXstudio. MiKTeX and MacTeX both come with LaTeX editors, so you can use those if you like (MiKTeX comes with TeXworks and MacTeX comes with TeXShop), though I prefer TeXstudio.

Once you have written your document in LaTeX and saved it as a .tex file, you will be able to compile it to a PDF.

Basic Formatting

A simple LaTeX file may look something like:

\documentclass{article}

% This is a comment
% This part of the file is called the preamble.
% Title / author / date can go here
% Can also include packages that we need to use to render the math correctly
\title{This is my title}
\author{My Name}

\begin{document}

% This is the main body of the document.
\maketitle

Paragraph 1.

Paragraph 2.

\end{document}

It can be overwhelming to start a LaTeX document from scratch, so feel free to use the problem-set files I post as a starting point. I include several packages, macros, and definitions in the preamble.

Formatting Math

To format math in a LaTeX file, you use dollar signs to start and end your mathematical notation. This is referred to as inline math mode. For example, to write the sentence “If \(a \neq 0\), then \(ax^2 + bx + c\) is a quadratic polynomial,” you use the following LaTeX syntax:

If $a \neq 0$, then $ax^2 + bx + c$ is a quadratic polynomial.

This is inline math because the mathematics appears in the middle of a sentence. There is also display math mode, which places mathematical content on its own line. Use \[ to begin display math and \] to end it.

As you can see, LaTeX uses commands to produce mathematical notation. For exponents or superscripts, we use the caret (^); for “not equal,” \(\neq\), we use \neq. You can find several good guides to basic LaTeX commands and mathematical symbols below.
